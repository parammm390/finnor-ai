# R5 original-input failure model, before implementation

The primary mathematical oracle is an independent Fraction reconstruction
and complete small reference. The primary integrated oracle is the real
authenticated owner/SQL/worker/native/checker/Capital Work flow. No fixture
supplies a solver receipt, owner clearance, consent, admission or settlement.

| Failure | Required distinguishing observation |
| --- | --- |
| Duplicate, missing, overlapping or foreign member | Exact party/coalition witness from the independent original-input checker |
| Partition-label symmetry changes value or hides a partition | Independently enumerate 4,140 canonical partitions; compare the fixed tie rule |
| Fixed coalition scores replace grant/programme-dependent value | Same members, different admitted programme/grant, different reconstructed payoff |
| Independent coalition winners cannot jointly fit | Joint alternative wins under the same complete S5 resource/cash basis |
| Hidden-state action/transfer branch | Same observable event/history cannot produce world-dependent contractual behavior |
| Local worst-case aggregation replaces correlated joint worlds | A supplied correlated-world counterexample has a different exact joint objective |
| Missing outside option, ownership or transaction cost becomes zero | Original-input absence/ambiguity is unsupported, with the missing coordinate |
| Payoff distributions double-count underlying owner wealth | Reconstruct canonical items once, then apply original ownership/objective weights |
| Wrong sign, unit, currency, owner or date | Named participant/item/amount/date violation; not an unrelated schema failure |
| Late receipts finance earlier payouts | Exact prefix-funding violation before the receipt's actual date/event |
| Transfers create money or assume a subsidy | Exact event/date conservation and identified paying-source failure |
| Continuous division silently becomes a payment grid | Production claim names continuous variables and exact accepted linear proof; grid reference is labeled |
| Spillover is dropped to preserve completeness | Supplied unsupported strategic cross-coalition mechanism refuses that claim |
| Candidate-pool bound or incomplete generation claims optimum | Missing family/partition witness leaves upper unknown and result incomplete |
| Crossed independently accepted bounds are clamped | Explicit check failure, retained original lower/upper, no completion claim |
| Solver status is mistaken for proof | Reject absent/mismatched VIPR, original encoding, model or primal correspondence |
| Consent proposal is treated as acceptance | Real S6 proposal/version/evidence states remain distinct; changed terms rebind consent |
| One coalition spends a shared grant twice | Two actual Works/coalitions meet the canonical S5 lock/reservation and original usage |
| Rights/method/model/resource changes after checking | Actual publication wait, revision change and fenced result retain checker/cost/history |
| Worker/child dies before acknowledgement | Physical SIGKILL evidence, original durable attempt/debit, no blind native/effect retry |
| Cancellation releases a still-live child or unknown liability | Physical exit and actual S6 responsibility determine release |
| Fallback receives a fresh grant/deadline | Actual existing S4 child executes under original remaining resources |
| Work switch/reload resurrects private output | Mounted identities/revisions and delayed responses do not cross scopes |
| Builder-only solver or wrong final Python/permissions | Installed final image executes actual pinned non-root solver/checker/owners |
| Optional R3 absence becomes invented truthfulness | No DSIC/core/stability/consent claim is synthesized |
