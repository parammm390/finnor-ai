# Exact finite information profile, specified before product code

The supported input is `finnor.s3.exact-information-model.v1`, supplied to the S3 owner from a current permitted S1 root and original Work revision. It is an explicit finite transition table, not a rational re-encoding of a learned numeric model. S3 retains its original UTF-8 bytes and current belief pins. The declared mandate, original S4 action catalogue, resource units, complete worlds, horizon, accounting conventions and assumptions are bound in those bytes.

Every state has an opaque ID, period, original action history and observations, complete world support, and required semantic fields: rights, pending observations, maturity, option conditions, exposure schedules and locks, resource capacity/usage/reservations/occupation/couplings, liquidity and covenants, human/compute use, staffing/compensation/benefit constraints, per-world accrued utility and S6 obligations. Empty collections are explicit declarations. UNKNOWN/PARTIAL/null liabilities remain in the model and prevent justified optimization; they are never zero-filled.

History is retained for lifting. Only the checked sufficient summary of catalogue at-most-once/prerequisite action predicates replaces history in a partition label. Arbitrary supplied sufficient-state projections are forbidden. All other state semantics remain in the label, recursively normalizing rational pairs. Original controller information keys must uniquely determine a state at a period; hidden worlds never select one. Every supported world's successor is explicit under each enabled action, preserving its original ID. Transitions increase period by exactly one, append exactly the selected original action, and deliver only registered observations at their declared availability.

Terminal accrued value is the complete full-horizon world payoff, including tail liability. Nonterminal edges carry exact discounted immediate utility and full resource/obligation deltas. Independently validate accrued-value, usage, observation, history, lock and obligation propagation against the edge and action catalogue. The source must state that all remaining obligations and terminal values are complete under its supplied model. This is an assumption, not field qualification.

Fixed-world objective: maximize the minimum complete-world value using lawful information-state policies. A probabilistic source additionally supplies exact complete conditional mass, a law ref, and an owner qualification reference. Structural mass checks run even when that law is unqualified. Certified probabilistic optimization requires actual current independent owner qualification; caller receipt-shaped JSON is insufficient.

The TypeScript producer refines a deterministic partition using normalized complete labels, each original enabled action, per-world immediate quantities and successor class/mass. The Python Fraction checker independently parses original bytes, validates the complete original table and every member of the relation, reconstructs quotient labels/transitions and verifies all lifting aliases. It imports no producer modules. A relation is accepted only in full. Any unverified candidate is ineligible for continuation reuse.

The actual S4 exact continuation evaluator evaluates the same original state graph with reuse disabled or enabled. The algorithm, exact arithmetic, complete candidate action order and stopping bounds remain identical. With accepted reuse it stores continuation answers by checked class; it reconstructs selected original state/history nodes separately. It retains symbolic optimal alternatives at every reachable information state, including later and root ties. Search completeness is separately bounded and never inferred from relation completeness.

Authoritative quantities are numerator/positive-denominator strings normalized with bounded bigint arithmetic. Numeric policy fields, where legacy presentation requires them, are marked display-only. S5 reconstructs exact original action demands from the retained exact profile, and its candidate producer may use numerical hints only before canonical exact feasibility and bound checking. Nonterminating rational quantities use a versioned exact string encoding at that adapter, never rounded demand.

Bounds are 128 original states including unreachable members, eight catalogue/enabled actions, twelve periods, 512 fixed complete worlds, 2 MiB source bytes, 128 input integer digits, 512 intermediate digits, four million mathematical operations, 50,000 lifted policy nodes and original owner deadline/episode/compute grant. Each is checked; failure is explicit and never changes the declared domain. The upper-bound fixture has all 128 states, eight actions and twelve periods with a tractable policy family.

Durable R1 runs attach to an existing original P1 Work episode and the authentic S4/S5 native-attempt allocation. Producer, checker, owner evaluator and original fallback are physical bounded children charged to that same grant and episode. Atomic admission uses the S5 portfolio lock and shared grant usage; queue claims, capacity leases, principal/Work/source revisions and original deadlines fence publication. Immutable sources, candidates, checker results, child attempts and heads retain prior costs and UNKNOWN outcomes. P7 maps each semantic dependency to affected R1 artifacts. It does not reset deadlines or turn S6 UNKNOWN into settlement.
