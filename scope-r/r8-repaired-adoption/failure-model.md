# Preregistered failure and test-value model

Registered before adoption or repair implementation. The source of the original
assertions is the retained real-owner driver and its final FAIL manifest, not a
new weaker interpretation. Finite budgets in verification-plan.json are fixed.

## Mathematical and compiler boundary

Failure modes: sampled or filtered D; repeated/missing indices; fewer than eight
subsets; cost subtracted twice; changed capacity or input order; wrong zero-cost
or tied optimum; overflow/coercion; false termination/fuel; eager lowering;
changed emitted/compiler/library bytes; inherited partial or wrong-candidate
chunks; counterexamples forgotten on recovery; declaring symbolic UNSAT to be
acceptance; a post-acceptance alternative inheriting the incumbent receipt.

Predicate: actual Rosette CEGIS produces a deficient candidate, Python reproduces
its counterexample on actual emitted bytes, later trials retain it, and each
accepted program covers exactly 262,144 inputs and 2,097,152 pairs in 64 bijective
chunks. Registered semantic/grammar/identity mutations must reach the original
independent oracle or correspondence refusal. Grammar and P1 caps stay unchanged.
Changing only process/transport location still requires new full-D acceptance.

## Physical process boundary

Failure modes: native startup refuses after the checker has already started,
leaving an unobserved checker; backpressured stdin hangs outside the response
deadline; an early rejection becomes unhandled; an already-cancelled operation
starts a new child; the normal close path releases capacity before descendants
disappear; cleanup done by the test is misreported as product cleanup.

Predicate: fault the actual process observer at native startup in both witness
and whole-domain entrypoints, and require every observed group to have its
product close event before the operation rejects. A bounded nonreading child
must reject its pending request under the original deadline without unhandled
rejection. Pre-aborted open must start zero children. A normally supervised
invocation must record physical disappearance. Test-forced cleanup is retained
separately and cannot satisfy a green assertion.

## Original owner and fixture boundary

1. Durable acceptance must also complete the registered cost alternative when
   budget permits; NO_REMAINING_BUDGET is not COMPLETE. The historical observer
   consumed most of its externally imposed original cap. No deadline reset,
   larger cap, removed cost assertion or cheaper-method claim is allowed.
2. Stop the test's scientific worker in a finally block even when its acceptance
   assertion fails; retain actual lease occupancy, group identities and close
   records before attempting canonical contention. Never forcibly release an
   unknown owner or relabel held capacity as empty.
3. Submit verifier/budget and locked-publication requests before slow unrelated
   review/mounted cases can consume the fixed campaign cap. Pre-create immutable
   grants; carry their exact IDs/deadlines through fault, fallback and publication.
   If the cap cannot reach the fault, report NOT_REACHED/FAIL, not a schema green.
4. Mutate an S5 resource using the actual strict resource preimage (including
   required ref/expectedRef), check owner readback changed, then require stale R8
   refusal while the abstract theorem and original incurred grant remain intact.
5. Record S8 server exit/signal, bounded stderr and transport cause on evaluation
   failure. A fetch failure alone does not establish its cause. No synthetic
   evaluation, admission or activation may substitute for owner execution.
6. Preserve S6 selected prerequisite plus interrupted-ack count of two. Its old
   exit-1 expected-count mismatch is not a suite pass; shared harness changes are
   proposals only.
7. Mounted Work proof must still be an actual built/authenticated API interaction
   with initiation, provisional progress, full coverage, executed fallback,
   reload, Work switch, delayed-response clearing and revoked-access clearing.
   A leaf component or historical login timeout does not qualify it.

Original owner predicates require shared S5 resolution, R8 schema/privileges,
canonical production queue registration, real API routing and S8 dispatch.
Without the integrator's assembled seams, they remain blocked, not isolated
mock-route passes. Any executable check of a proposal is labeled separately
from compatibility of the delivered cumulative branch.

## UI privacy boundary

Failure modes: old context or draft displays for one render after Work, root,
principal or access-token changes; late results repopulate a revoked scope;
URL request identity changes without fencing an older response.

Predicate: every private state value is scope-bound and gated during render, not
only cleared in a later effect; request identity participates in epoch fencing.
Mounted red/green is required for browser qualification; structural review alone
is explicitly insufficient.
