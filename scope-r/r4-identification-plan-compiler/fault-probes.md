# Registered remaining owner and physical probes

These probes extend the pre-code failure model. They are E2E challenges, not
post-implementation unit tests or production fault callbacks. All mutations
are in the new disposable cluster or agent-owned staging files.

One campaign uses at most eight real owner fixtures and 32 actual native
deliveries. Every fallback names
`synthesizeEnterpriseControlProposal -> chooseEnterpriseControlBranch`,
the current ordinary WAIT/STOP domain, the original episode and expected
disposition before the triggering action. No protected collection fallback is
available for this observational profile.
