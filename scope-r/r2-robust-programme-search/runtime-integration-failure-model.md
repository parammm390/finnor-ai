# R1/R2 runtime integration

Specified before changing the runtime driver. This is an actual owner E2E, not a new unit suite.

Failures to distinguish:

1. A stale workspace link executes another checkout instead of the adopted source.
2. A hard-coded interpreter or native directory silently selects an absent or different runtime.
3. R2's migration replaces R1, repeats ordinal 0172, or alters historical role isolation.
4. The final image overwrites R1's pinned Python environment or drops its allocation lock while adding R2.
5. Version dispatch sends an R1 branch choice to R2's different policy format, or the reverse.
6. A source merge or solver return is reported as owner acceptance without authenticated SQL, real worker/checker, original policy and canonical S5 consumption.
7. A timed-out child, owned database or unknown responsibility disappears from evidence or causes a blind retry.
8. Mac Seatbelt success is described as Linux P1 execution. The adopted R2 P1 isolation implementation currently supports macOS only; that Linux engineering gap remains explicit.

Acceptance uses the existing `authenticated-contingent-owner` and `authentication-and-private-scope` cases, plus the R1 positive owner case on the cumulative source. Preserve original 30-second accepted decisions. Prepare the worker before admission. Bind every configured executable, exact native manifest and current source overlay.

The compatibility lane upgrades an actual R1 schema to R2 ordinal 0173 and restarts the owned database. It must preserve 0171 role isolation and R1 tables/jobs. Generated bundle/head/contract/canary must name the same chain. Keep original mathematical receipts only where their relevant semantics/checker/native vector is unchanged.

Finite owner-driver ceiling: the original 1200 seconds. New output directory per attempt. Wrapper records exit/timeout, executable hashes, actual source and child usage; no fixture supplies a scientific receipt. A missing result or any failed case fails acceptance. Child high-water is not aggregate simultaneous memory and unknown dollars remain unknown.
