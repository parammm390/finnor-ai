## Coordinator note 20:33 (rbg.sh pitfall)
`rbg.sh NAME ...` GENERATES `fzv-int-out/scripts/NAME.sh` (a wrapper that `exec`s the ABSOLUTE_ARGV). If ABSOLUTE_ARGV is `scripts/NAME.sh` itself, the wrapper overwrites your script and `exec`s itself in a loop (PATH grows until `Argument list too long`, exit 126, e.g. w1-native-07 and w3-gov-06). Either write the run script under a different name and pass that path as ABSOLUTE_ARGV, or start a hand-written script directly with `(nohup fzv-int-out/queue-run.sh NAME stack CWD >/dev/null 2>&1 &)` (never use the same NAME for both). Those two runs are harness errors, not product evidence; keep their logs and use a new NAME.
