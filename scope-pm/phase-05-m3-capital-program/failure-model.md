## Qualification and boundaries

The local end-to-end path is native inputs → sealed immutable native base → permitted semantic grammar → candidate-specific native config/snapshot → compiler → executor → PROPOSED/owner-blocked envelope → deterministic finite search → independent rational comparison and repeatable evidence.

Financial money is an unformatted decimal string in the native config's single currency, scale 1. Contractual interest is a fraction per year using native ACT/365F. The development objective is discounted sponsor cash flow at a declared **per-native-period** discount fraction, less declared implementation costs and the complete declared evaluation liability. It is not S4 utility, actual metered spending or a causal/economic outcome.
