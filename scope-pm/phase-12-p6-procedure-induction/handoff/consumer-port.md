# Ordinary consumer port

Version `p6-exact-structural-v1`; capsule schema `finnor.procedure-capsule.v1`.
Domain: finite exact single-entity/period source-backed P1 arithmetic, including
branches supported by P1. Source aliases/layouts/entity/period and actual values
are explicit input bindings. Currency, unit, frequency, calendar, consolidation,
instrument, scale, sign, literal and branch meaning remain invariants.

The ordinary archive is not an S8 capability registry. Source qualification is
`AUTHORIZED_COMPLETE_DECLARED_NATIVE_EPISODES_NOT_PROTECTED_LEDGER_OR_CAUSAL_TRUTH`.
Every endpoint uses the existing Company Brain bearer, user, tenant and resource
authorization. All requests are bounded and strict. Generated bytes run only in
the existing credential-free S6 local isolated executor.

P1 extension: `procedure:{capsuleId,mode}`. No caller-provided module, evidence or
admission is accepted. Subtree matching is structural and injective. The capsule
core and native residual execute separately. PostgreSQL checks the **original
whole acceptance**; current P4 witnesses and capsule revision are retained.
Mismatch/invalidity/failed execution records costs and triggers actual fresh P1
execution within the original grant. Rights loss stops instead of synthesizing
against unauthorized inputs. Protected mode always refuses.

P7 proposal: `assertProcedureContinuationIntake` allows only historical
inspection for fresh recomputation. It does not validate invalid bytes for use.
Existing source rights/Work/plan/compiler/schema checks and authentic changed
dependency/consistency-vector requirements remain. The next P1 request shares
the original episode/grant/deadline and performs real fresh fallback.

P5 practice/observation owns the consequential system result. Pure dependency
rehearsal cannot dispatch even a target read. UNKNOWN is retained and never
discharged by a capsule result.

declare source episodes and knowledge cut, inspect exact domain/history, select
a disposable proposal, execute current inputs through P1 and append a correction.
Identity/Work/auth changes and failed verification hide private/ready evidence.
