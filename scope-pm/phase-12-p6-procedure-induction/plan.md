## Architecture of the ordinary implementation

- Reuse P1's bounded arithmetic AST and semantic TypeScript compiler, P4's
  authorized source resolution and independent numeric checks, S6's existing
  credential-free Seatbelt executor, canonical Work and the native job queue.
- Normalize expression dependency roles, output types and material acceptance,
  not task text. Source kind/layout/field aliases are explicit bindings.
  Entity and period identifiers vary; units, currency, consolidation, calendar,
  frequency, instrument, scale, sign, branch conditions and numeric literals
  remain checked invariants. Unsupported generalizations are rejected.
- Require support from distinct native episodes/companies. Keep all requests,
  heads, attempts, costs, failures, declines, incomplete and unknown paths in
  the declared universe. A successful subproblem does not erase its episode's
  unknown consequential continuation.
- Run generated executable bytes only through the existing isolated executor.
  A larger P1 programme may use the capsule for an exactly matched subtree and
  compile a bounded residual. Independently check the **original** full
  acceptance, never a rewritten objective.
- Persist immutable capsules and counterexamples. Mutable selection/request
  projections are fenced and do not own beliefs, admission or effect history.
  New adverse evidence increments an ordinary dependency key. P1 currentness
  and P7's existing affected closure consume that key.
- Protected selection/use always refuses until the owner-reviewed versioned
  S8 transport and release exist. Ordinary evaluation is explicitly
  `TEST_ONLY_NO_S8_ADMISSION`, not permitted deployed reuse.
- Missing, incompatible, revoked or failed selection performs the existing
  fresh P1 path if its original grant allows it. Charge lookup and failed
  isolated attempts as well as that path. Cancellation/rights loss never
  triggers unauthorized fallback.
