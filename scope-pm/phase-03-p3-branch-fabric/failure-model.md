# Failure-first observable protocol v1

Frozen before product code. No unit tests will be authored after implementation.
Tests run in an exclusively created loopback PostgreSQL cluster through the real
migration runner, ordinary `finnor_app`, real queue, subprocess, independent
checker and consumer. No ambient DATABASE_URL is accepted by the runner.

Every case writes inputs, expected predicate, steps, before/after state,
observations, checks, attempts, usage, outcome and rerun command. Each run binds
source and protocol hashes before/after. Failed runs are retained in distinct
directories. Unexecuted/blocked/filter-excluded cases are not passes.

## Public oracles
Declared EV/EBITDA/debt/equity/payoff:
A120/20/70/50/20, B100/25/50/50/18, C90/15/45/45/14.
Equity95 + leverage3.5 → A+C34; leverage3.0 → B+C32;
reserve25 leaving70 → A20. BigInt cents and exhaustive independent enumeration
check the finite answer. These are synthetic fixed payoffs, not predicted returns.

## Fault injection
The runner controls injectable observation hooks, not caller JSON or programme
capabilities. A hook may kill the controller/child or fail after a durable write;
the expected oracle does not change. Before/after SQL readback is independent of
the worker receipt. Teardown awaits child close, not merely signal acknowledgement.

## Setup failures retained
Two pre-code receipt attempts failed: a nonexistent `@finnor/governed-execution`
package alias, then an extra parenthesis in the inspection command. Governed
execution is a real relative source directory, not a workspace. Receipt capture
is repaired without editing an owner or lockfile. These are setup failures,
not passed product challenges.
