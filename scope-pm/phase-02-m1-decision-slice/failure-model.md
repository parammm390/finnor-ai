# Failure model, authored before M1 production code

The oracle is specified independently of compiler output. All tests are owner-boundary or end-to-end tests, not post-code unit tests. Public/generated fixtures are H0/H1 mechanics evidence. They are not sealed novelty, hosted authentication, protected admission or H2 economic evidence.

| Challenge | Credible failure | Observable boundary and independent oracle |
