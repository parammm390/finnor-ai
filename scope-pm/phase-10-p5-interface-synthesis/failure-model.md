# Failure-first model

Registered before product code in this checkout. All 34 original families
are copied from the immutable governing mission by `record-baseline.mjs`.
Registration is immutable. Results and coverage are separate append-only runs.

## Primary boundary stories

1. Read actual permitted API documentation from an independent process. Freeze
   its exact bytes. Synthesize parameterized adapter and observer modules.
   Perform a real conditional write, then independently read persisted target
   and decoy state and original operation history. Compare to separately
   formulated integer/decimal constants, not production conversion helpers.
2. Open a real disposable web application backed by that process. Duplicate
   labels, reversed controls and variant wire names must not change identity.
   Generate and execute a bounded UI module, then read state independently.
   DOM/headless proof and Factory browser input/screenshots are separate cuts.
3. Actual authenticated Company Brain dispatch, PostgreSQL/RLS and JobQueue
   accept and publish a capability under an existing Work input. Current
   readers, module export and projection reauthorize and verify immutable
   bytes. A forged context, other principal, stale Work/rights/lease, corrupt
   module, expired grant or cancelled worker cannot publish a current result.
4. Kill a real owned worker before egress and after the target persisted a
   mutation. Recover using the original durable frontier. Possible egress
   forbids mutation replay. Lost read access retains UNKNOWN and responsibility.
   Cancel does not release an unknown effect or renew an exhausted episode.
5. Use the actual S8 lifecycle, separate actors/keys, signed journal and S6
   owner-reference transport. A proposer cannot register its own evaluation,
   admit itself, change a signed domain, substitute modules or reuse a revoked
   revision. S5 regressions retain their original assertions.

Credible regressions include display-name matching; scale truncation; $20/$200
confusion; missing-as-null; acknowledgement-as-proof; redirected schema fetch;
arbitrary imports; credential leakage; unrecorded mutation; reset retry identity;
late publication; optimistic current cache; self-evaluation; forged programme
or rehearsal references; incomplete cost accounting and unsafe cleanup.

Isolated codecs protect import/ref/byte/depth bounds and exact arithmetic.
Their expected values are independently specified here and in the target
driver before feature code. They are grouped with network stories, not
post-code mirrored unit tests. No test-only product flag, oracle callback or
synthetic admission is permitted.

## Frozen facts and accounting

Public development targets: `C_01` and `C_010`, identical human labels;
`test-account` and a separately unauthorized account; USD `20.00` means
2000 minor units; both initial values are 1000; revision `"v1"`; exact null
is not absence, empty text or zero. Independently read both records and every
write after each operation. A wrong write followed by correction is still a
violation. Variant names/layouts are public development, not sealed novelty.

The target owns its persisted file and append-only mutation history. The
producer sees permitted documentation/UI/readback, not reference assertions
or administrative target state. Crash cases use PID kill/reap, not caught
exceptions. Original failures, NOT_RUN selections, interrupted writes and
storage failures remain retained. USD, sealed gate, equipped comparison,
production trust, scientific/H2 and aggregate-resource compliance stay unknown.
