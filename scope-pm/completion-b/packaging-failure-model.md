# Early immutable packaging failure model

Registered before writing the publisher. This is source/evidence reconstruction,
not runtime or independent gate qualification.

- A dirty or staged checkout is labeled as a committed producer. Refuse packaging.
- A peer generation, active checkout or new source is substituted for the exact
  B commit/base/tree. Pin the committed B range, verify every patch's exact parent
  and tree in an independent disposable index, and verify the final bundle/tree.
- Private original bearer/claim tokens, credentials, keys or runtime stores are
  copied into Git or a coordination export. Exclude private raw directories.
  Keep originals in place; export only reviewed summaries, hashes and source.
- A source/runtime manifest references missing or changed bytes. Hash every
  referenced artifact and refuse a moving source during packaging.
- A historical green is applied to the current cut or an excluded/failed cell
  disappears. Export actual counts, unchanged deadlines, failed predecessors,
  the current source-cut limitation and explicit pending original affected suites.
- A copied runtime is called a clean install, a source bundle is called behavior
  proof, or local no-witness is called SAFE/admission. Retain those distinctions.
- A half-written generation becomes current, or an adopted generation is
  overwritten. Stage outside generations, name by receipt content digest, publish
  by atomic local rename, then atomically replace only B's current pointer.
- Packaging changes peers or invokes push/deploy/provision/live services. It may
  only read immutable peers and write B's own local coordination directory.

Validation must independently apply exact-parent patches and reconstruct the
commit/tree, compare tracked source archive digests/modes and all receipt hashes,
then report `PASS_SOURCE_ONLY`. All three gates stay unqualified.
