# Mounted emitted Work checks

Run the maintained Next frontend and emitted API with ordinary signed local
users and PostgreSQL roles. Fixture preparation may create source inputs and
the already-declared native training lineages. Browser actions must grant
explicit consent, inspect experience, submit a new original Work compilation,
run the ordinary physical queue, execute fresh native use and observe it.

Retain request/response and SQL evidence, model/load/queue identities, browser
steps and a screenshot under the workspace. A screenshot alone is not a pass.
Use a named task-owned `agent-browser` session and the actual login form.
Never inspect or copy credentials, storage, cookies or tokens into artifacts.

Required browser falsifiers:

- Delay an actually committed `learning-execute` response through real
  automatic signed-session refresh. Run the ordinary queue while held. Release
  success, then on a different fresh record release a transport error. In both
  cases the old response cannot resurrect private state, and retry must send
  the exact original body/idempotency/CAS. There must be one durable use and
  one native reconciliation, not a new invocation on the changed record.
- Hold an actual prior Work's list reply, navigate to a different original
  Work/root, then release both success and error in separate trials. Neither
  late response may restore the old capsule or clear the new scope.
- Reload, sign out and sign in through the real forms. The component must
  derive scope from the current signed identity and current server Work, not
  a persisted old capability. A different principal cannot reuse another
  principal's uncertain local request.
- Revoke consent through the visible control. Current capsule and execution
  controls disappear, while honest history and revocation remain visible.

A second Work created for browser compilation is a separate finite UI proof,
not another independent scientific assignment. It does not add to the frozen
32-case demand. All local auth, signers and infrastructure remain disposable
builder-controlled development authority.
