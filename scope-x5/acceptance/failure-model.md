# X5 failure model, fixed before product code

Primary boundary is authenticated Work/API, durable queue, actual compilation
and training child, fresh native application command, different-principal
acceptance and ordinary SQL readback. Local development authors and credentials
are builder-controlled; independent implementation is not protected custody.

| Family | Credible defect | Independent observable expectation |
| --- | --- | --- |
| Acceptance | forged positive label or altered checker/ref | resolve exact native history; no receipt input can create success |
| Original contract | approval spec/trace omits reconciliation | reject positive learning even if final state looks successful |
| History | omit refused sibling, edit after acceptance or incomplete enumeration | retain nonpositive labels and refuse stale/incomplete success |
| Time | future event at historical knowledge cut or late commit | no future/late-committed event enters positive data |
| Rights | read access treated as consent, revoked/expired train/reuse | fail at current consent owner before training/use |
| Privacy | tenant IDs, text, amounts, credentials in features/checkpoints | structural boolean samples only; no private values in portable policy |
| Partitions | repeated institution/structure/time counted as independent transfer | manifest marks public/dependent; no protected claim |
| Compiler | ID-selected or transcript replay | fresh names/records run without source or candidate repair |
| Guard | known/equality/currentness/approval dropped | owner denies; guard cannot waive canonical interpreter checks |
| Domain | changed consistency, roles, version, missing observations | actual native fallback or explicit wait/block; unchanged required check |
| Training | fake job/loss-only/checkpoint rename | numeric parameters train, save/load and change actual fresh behavior |
| Attribution | prompt/tool/provider/context change credited to weights | original/new reruns fix all non-neural surroundings and inputs |
| Loading | checkpoint replacement, stale loaded model, missing assets | exact loaded parameter/procedure digest mismatch refuses |
| Authority | client chooses principal, stale role or old grant transfers | authenticated fresh principal/tenant and canonical role checks |
| Effects | retry duplicates uncertain effect or checkpoint rollback clears it | pending effects block; S6 identity/UNKNOWN and obligations survive |
| Evaluation | supplied pass rows or favorable average hides critical loss | read actual outcomes, retain all assigned failures, critical floor blocks |
| S8 | training self-admits or payload masquerades as allocation method | typed learned-policy route, separate evaluator/promoter, exact source pins |
| Lifecycle | revoked/harmful capability stays current | currentness/ref/use deny; earlier revision only if still compatible |
| Durability | checkpoint published partially | atomic durable release only after complete child/checkpoint validation |
| Concurrency | stale/duplicate physical delivery overwrites successor | physical claim and domain generation fences, idempotent original identity |
| Recovery | restart refreshes deadline/budget or swaps parameters in flight | original counters/deadline/method identity remain fixed |
| Cancellation | surviving child publishes after cancellation | monitor kills/fences; no accepted release |
| Accounting | failed training/fallback/storage/repair omitted | append original attempts; unknown money/labor/memory never zero |
| Work | delayed response resurrects prior Work/tenant/token/capsule | scope epoch clears private state; stale response ignored |
| Packaging | trainer only in builder or hidden donor dependency | final installed entrypoints/checkpoints run from standalone reconstruction |

Tests must state the contract, credible defect, primary owning boundary, why
existing coverage misses it and literal expectation. No self-comparison,
mock-owned persistence, supplied acceptance rows or early unrelated denials.
No unit tests are added after implementation.
