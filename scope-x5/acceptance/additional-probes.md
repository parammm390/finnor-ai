The late-commit fault uses a disposable AFTER INSERT trigger that waits on a
held advisory lock. The actual signed native approval creates its own record
and event. The fixture changes only timing, never the result or its timestamp.
Release every gate and drop the fixture trigger in cleanup, including failure.
The selected K is fixed while the actual owner transaction is still open.
Retain actual event creation and PostgreSQL commit timestamps.

History overflow uses genuine allowed edits followed by fresh reconciliation
and independent approval, not forged event rows. Selection must fail closed
even though the final native state is approved.

These probes do not establish protected custody, complete fault/exhaustion
coverage, elapsed-deadline harm, or browser/emitted-runtime qualification.
