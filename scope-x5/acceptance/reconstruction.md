# Clean installed reconstruction failure model

Register before reconstructing the final local source. No new unit tests,
alternate trainer, manufactured accepted outcome or provider stand-in.

| Failure | Required observation |
| --- | --- |
| Hidden donor source/build/modules | Clone only a local Git bundle into a new absolute directory; initially no `node_modules`, `.next` or private fixture directory |
| Unlocked dependency graph | Ordinary `npm ci` against both unchanged lockfiles; retain exact Node version and command exits |
| Workspace aliases resolve into original checkout | Resolve installed workspace package paths and require the new clone root |
| API source stamp/build drift | Ordinary emitted API build, X3/X5 stamp checks and all producer-file byte hashes match the sealed source inventory |
| Missing physical training/inference assets | Run the existing installed `smoke` entrypoint from the clone, through fresh signed HTTP, SQL, ordinary queue/delivery and actual fixed child |
| Metadata-only model reconstruction | Fresh native experience yields real changed coefficients and actual loaded digest; run the independent numerical reproducer on retained training output |
| Migration/upgrade drift | The existing disposable environment replays the bundled ordered migrations and retained parent/in-flight sentinel; read its artifact |
| False broad qualification | A reconstructed smoke proves the installed path, not another 32-case population result or protected custody |

Retain failed install/build/installed runs. Do not copy caches, signers,
credentials, tokens or another run's durable database. A fresh rerun creates
fresh governed identities. It is not permission to load an old private capsule
under new rights, and it is not a restore of an expired admission.
