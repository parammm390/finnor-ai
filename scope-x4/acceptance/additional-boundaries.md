# Additional review-boundary observations

These refine the existing B/C/G/H/I failure model. They do not change the frozen
domain, tolerance, provider lifetime, original allocation or acceptance predicate.
Failures and interrupted runs remain retained.

* **Retained instrument:** a calibration can be producer-valid while the
  independent literal event-timing check fails. A real retry must retain that
  certificate, spend a new original-parent analysis unit, rerun the independent
  check and still cause zero physical experiments. It must not infer validation
  from the producer's disposition or silently recalibrate.
* **Canonical Work:** cancellation through the ordinary canonical Work owner,
  both before wire and after a checked release, must fence current use. A prior
  checked model and S8 admission cannot override it. Finished experimental child
  actions alone must not mark the still-waiting scientific Work completed.
* **S8 lost response:** forward the real signed proposal to the real disposable
  native lifecycle service. After the service accepts and returns its genuine
  response to the transport boundary, destroy that response before the caller
  receives it. At that point there must be one native proposal and only the
  original local proposal-registration marker, not a local successful result.
  Concurrent exact retries must reuse that registered candidate and create one
  canonical local result, with one native proposal identity after restart.
  A proxy may drop transport; it may never invent a lifecycle response, grade,
  evaluation or admission. Scientific counters, deadline and physical effects
  must not be renewed by this recovery.
* **Slow mounted read:** hold an actual emitted owner read beyond the real
  four-second UI polling interval. No overlapping poll may replace its epoch.
  The same Work must display the useful response after release. Work/identity/
  token change, explicit reload, offline and reconnect still own their fences.
* **Packaging:** compare every required raw scientific source and native facade
  against the emitted route's actual trace. Builder-local availability is not a
  passing expectation. Load the real native flock ABI. Container/arm64 execution
  remains a separate, explicitly unrun boundary without its toolchain.
* **Mounted evidence integrity:** concurrent large real owner replies must not
  interleave bytes in the fixture's JSONL receipts. Serialize whole records,
  drain outstanding handlers/writes on close, and retain write failures. A live
  reader may defer only an unfinished final record; malformed complete records
  remain failures. Stopping a fixture is not a passing browser result.
* **Native interaction readiness:** browser actions must respect the actual
  enclosing disabled fieldset, not only a button's own `disabled` attribute.
  Require native HTML form validity before keyboard submission. Do not insert
  state, manufacture an owner request or bypass ordinary controls.
