# Product delivery regression contract

Written before the production repair. Main baseline is c12665661c1a536a2350aeb8abc01ac42aa16548.

## Failure model

A declared backend owner operation can be absent from the product catalogue, shadowed by a generic UUID segment, misclassified as a mutation, denied by an unrelated policies prefix, or called through a frontend URL that has no handler. A generator can omit delegated registries. Coverage can falsely certify dynamic strings, miss imported aliases, count unused wrappers, or remain stale in CI. A successful proxy response alone cannot prove a worker result or customer outcome. Session/Work changes can leave stale private responses visible. An accepted mutation can time out without becoming safe to retry.
