# Direct economic read contract, before implementation

No new router names, scheduler, financial ledger or source-rights registry. Extend the existing QUERY lane with typed economic reads. A read never acquires a child, sandbox, business-capital reservation or consequential effect, including unavailable/ambiguous sources, replay and already-classified core entry.

## Canonical sources

Revenue reads the actual `pe_metric_series`/`pe_metric_observations` financial owner, joined to its immutable S1 evidence source/version. Invoices are not revenue. A typed source statement must match legal entity, exact recorded accounting month, accounting calendar/time zone, currency, cash/accrual basis, consolidation boundary, amount and provisional/closed status. A configured tenant operating profile resolves “our” and the owner's month boundaries; missing conventions are a read-only clarification, not a guess.

Quotes read authorized recorded licensed-feed source versions, not web snippets or model memory. Resolve instrument, exchange, issuer/company, currency, provider timestamp, market session, actual delay and license/validity. No fresh lawful source means UNAVAILABLE or explicitly STALE, never a fabricated current quote or a trade. Current source permission and revocation are resolved by existing S1/authority owners. Public/private/source classes are not interchangeable.

No reader writes financial facts. Canonical source/metric ingestion retains its owners. New reporting/quote schemas describe exact existing-owner bytes and current rights, not new grants.

Recognize ordinary last-month revenue and quote questions before objective signals, memory, readiness checks or planning. “Ensure I know”, “coordinate”, “deadline”, and explicit “do not act” context cannot by themselves turn a supported read into owned-outcome work. Actual positive send/purchase/trade/mutation/standing mandates remain outside this direct grammar. Retrieved instructions are not original user intent.

The same semantic guard runs when a caller supplies a prior classification or requests skipFastReadClassification. A genuinely separate lawful action trigger retains its own authority and is not erased by an unrelated read.
