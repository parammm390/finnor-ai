# Portable W1 campaign failure contract

Registered before the portability repair. This changes local execution setup.
All original business predicates, independent oracles, deadlines, critical
cases, privacy controls, and separate qualification states remain required.

The credible failures are:

- A copied checkout still requires a former workstation's executable, browser,
  temporary environment, coordination directory, Git object, or input directory.
- The exact driver invokes an unqualified PATH `python3` despite a frozen
  `FINNOR_TEST_PYTHON` entry, or an isolated `-I` numerical preflight ignores
  `PYTHONDONTWRITEBYTECODE` and changes the attested Python population.
- A malformed configuration, missing file, changed hash, symlink escape, stale
  scientific attestation, incomplete structural population, or omitted SQL
  migration reaches execution instead of failing before freeze.
- The recorded host has invented memory or CPU capacity. A Linux wrapper calls
  macOS resource commands, admits an impossible disk forecast, or ignores its
  frozen disk budget while a child runs.
- Two W lanes hold the shared heavy slot at once, a nested wrapper deadlocks,
  or interruption releases a peer's lock or removes a peer's namespace.
- A child exits while a descendant still holds the owned temporary directory.
  A missing cleanup tool, a truncated process command, or a failed closer hides
  the remaining process. Cleanup must fail closed and attempt every finalizer.
- Recovery loads unavailable Git history or restores the wrong repaired bytes.
  The packet must retain the exact original broken source and contract hashes.
- A sealer requires private CONTROL evidence at an old checkout path, omits one
  of the original 53 files or 11 shield flags, changes a byte, prints private
  bodies, or includes private evidence as cold application dependencies.
- Cold installation reuses donor dependencies, a venv, compiled runtime, or an
  unpinned bootstrap tool. Source, locks, migrations, scientific assets, and
  installed asset populations must remain identical before and after owning runs.
- An old migration count rejects a correct current schema or accepts an omitted
  migration. Source names and actual database names must match exactly.
- A short local process check is reported as W1 functional completion, native
  proof, protected qualification, admission, field evidence, or a cold pass.

The primary proof for wrapper admission is its real CLI, shared `flock`, actual
Python child, receipt, process session, and owned directory lifecycle. A finite
lightweight verifier records inputs, commands, expected exit/status, observed
receipts, and source hashes. It does not boot FINNOR or substitute for the real
API, queue, physical worker, PostgreSQL, browser, installed, and cold stages.

Configuration validation and syntax can run on the current host. No dependency
download, build, scientific population enumeration, or cold run is allowed
while capacity is below the frozen 3 GiB global floor plus stage forecast.
Full campaign freeze requires a clean reviewed commit and actual runtime pins.
Required owning, recovery, on/off, headed, emitted, scrutiny, and full cold
gates remain NOT_RUN until executed on that exact frozen cut.
