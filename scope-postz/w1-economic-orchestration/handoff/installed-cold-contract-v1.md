# W1 emitted owning suite and cold packet contract

Registered before the corresponding emitter, launcher and packet code.
This does not authorize deployment, external effects or completion claims.

## Installed development gate

Materialize an independent task-owned runtime with canonical source assets,
both original npm locks and installed dependency bytes. No dependency or
workspace link may resolve outside that runtime. Copy-on-write regular-file
copies are disclosed for this installed gate; they are not a fresh install.
Reject source or lock drift before and after emission.

Emit the unchanged original P2 A/B/C owning suite and the actual separate
physical worker with the pinned esbuild dependency. Bundle the actual API,
W1 controller/consumer and independent observer. Preserve function names and
all original assertions, roles, grants, limits, costs and business deadlines.
Retain the emitter metafile, input/output hashes and actual child arguments.

Reuse the established @finnor/source-custody adapter for original relative
Python/SQL/producer assets. Record every import.meta metadata transformation.
The sole fixture-launch transformation changes the physical worker filename
from physical-worker.mts to its emitted physical-worker.mjs sibling; preserve
the original preload, environment allowlist, role and process bounds.
No product source or scientific oracle is rewritten. Explicitly disclose any
remaining source-loaded predecessor adapters.

At execution, reject source-loaded W1 economic-orchestration, metalevel-policy,
compute-search and Company Brain API modules. Observe the compiled physical
entrypoint and its digest through the existing fixture IPC observation path.
The actual source-loaded predecessor adapters remain separately recorded;
their presence is not described as an entirely source-free runtime.

Require all three original P2 owning IDs and the actual W1 native owner story,
their independent SQL/Fraction/native oracle, real physical child shutdown and
zero child exit codes. A producer's existing wrapper success is insufficient.
Preserve every failed install, emission, child, shutdown or oracle result.
Require the owning bootstrap's completed shutdown and exact registered
PostgreSQL stop/directory-removal receipt as well as the zero process exit.
Every finalizer is attempted even if another one fails; interrupted launches
must still terminate their owned sessions and retain a failed gate receipt.

## Sealed packet and independent cold gate

Seal canonical original source/locks/assets, these exact reconstruction
scripts, governing requirements and all retained W1 evidence. Include the
eleven shield-blocked CONTROL originals byte-for-byte under their existing
53-file sidecar. Never print, redact, force-add or bypass their shield.
Do not package credentials, .env files, donor node_modules, a venv, Git
alternates or old compiled runtime as cold dependency inputs.

Verify every archived member against its SHA manifest before extracting only
the source/governance inputs into a new directory. Cold npm dependencies must
come from two actual npm ci operations under the two original locks. A
disclosed package-cache reuse is allowed; donor node_modules/runtime/venv
copies and dependency symlinks are forbidden. Create a new Python environment
with exact numerical dependency versions and record installed identities.
Reuse the existing S3/S4/S5 disposable verification dependency pins, including
the unchanged S3 statsmodels/arch/pandas dependencies, rather than installing
only S5's NumPy/SciPy pair. The isolated cold temporary directory is a new
identity-checked child of the admitted resource wrapper's namespace. Thus an
interrupted or hard-killed nested launcher cannot strand a PostgreSQL cluster
outside outer custody. Remove that namespace only after all owned children
are stopped and the independent namespace cleanup observes no open owner.

Build and run the same emitted owning suite from that materialized source.
Bind packet digest, original source pins, both locks, migrations, runtime
executables, fresh dependency inventory, emitter and child reports. Keep cold,
installed, UI and native development gates separate from domain admission,
production activation, field validation and economic gain.

The shared heavy/medium locks, 3 GiB global free floor, 4 GiB net-new W1 budget
and original finite bounds still apply. Seal and verify generated artifacts
before scoped cleanup if space must be reclaimed. A capacity refusal is
NOT_RUN, not an internal PASS or an external qualification exception.
