# Pre-implementation failure and independent-observation contract

Written before W1 controller, estimator, checker and oracle implementation. This is a development specification, not a qualification receipt.

## Original semantics and exact policy

- A missing state, action, observation, history component, resource, existing obligation or check can make a smaller model falsely optimal. Parse all original bytes; reject unsupported bounds without truncation. Exact claims are conditional on the supplied complete-state model, never a proof of real-world completeness.
- Float conversion, invalid probabilities, negative costs, duplicate identities, dangling successors, hidden zero-probability branches, altered horizon, implicit invalid observations or ambiguous ties can change the optimum. Use rational strings throughout exact decisions. Validate the entire model, including unreachable supplied rows. Specify one total tie order in the original input.
- A myopic value-of-information score misses complementarity. The independent original-byte reference must find initial stop 50 and two one-unit computations 98. It must evaluate full contingent continuation, not sum per-agent benefits.
- Correlated errors and nonadditive/context-harmful responses cannot be represented as independent votes or additive arm effects. Preserve their joint outcome and full-state conditioning. Unknown response is not positive ROI.
- Stopping cognition is not accepting a business result. Every stop keeps the original acceptance reference and independent accepted/incumbent/incomplete/unknown disposition, unresolved obligations and effect identities.
- A checker importing producer selection helpers, trusting producer values or accepting a different model is circular. A Python standard-library Fraction reference reads the original model bytes independently. The production checker separately reconstructs Bellman predicates, all alternatives, exact values and declared ties from the original parsed input, not producer certificates. Neither establishes protected independent custody.

## Measured response and learning

- Association is not a causal marginal benefit. Keep assignment/exploration protocol, population, selection probability, censoring, human rescue, source/model/method/price/checker revisions and cluster lineage. Unsupported identification is reported, not silently fitted as causal evidence.
- Train/calibration/held-out partitions cannot overlap by original Work/independent unit. Held-out outcomes cannot influence fitting or online selection. Each retained observation needs independently accepted quality and actual measured latency/cost, or a named unknown.
- Joint topology/context combinations are fitted as joint treatments. Do not interpolate absent combinations, assume monotonic effort, or multiply correlated agreement into confidence. Common-premise drift invalidates every affected bucket.
- Update state by immutable dataset/sample identity. Retries cannot duplicate evidence, erase failed/censored work, change the split or reset the original resource grant. Unknown dollars remain unknown.

## Runtime and ownership

- A persisted capsule with an unchanged fixed loop is not consumption. Observe the actual native dispatch payloads, branch dependencies/context edges, independent checking and stop transition.
- Foreign tenant/principal/company/Work/mandate/outcome, expired rights/deadline or changed checker/model/price/runtime must fail at the actual time/trust boundary. Recheck submit, claim, check acceptance, publish, use and effect dispatch with existing P7 dependencies.
- Resources belong to S5, effects to S6, costs to S7, promotion to S8. A proposed computation creates no grant. Descendants, retries, fallback, monitoring and controller overhead consume the same parent episode and physical occupancy.
- A crash before/after claim, check, persistence or possible egress must retain fencing, durable progress, actual cost, original S6 identity and UNKNOWN. A new topology is not a resend permission. Reconciliation is independent.
- Failure, drift, unsupported input and exhaustion use only a current compatible native checked incumbent/fallback within the original remaining budget/deadline. No fresh episode, removed checking or invented successful receipt.
- W1 uses existing predecessor actors. W2 lifecycle is neither duplicated nor awaited. Shared-file changes are exact preimage-bound proposals applied only by the acknowledged single writer.

## Direct reads and mounted Work

- Supported ordinary revenue/quote reads, including misleading objective words and retrieved spawn instructions, must keep child agents, sandboxes, new business-capital reservations and consequential effects at zero at intake/core/retry/background boundaries. Observe canonical ledger/queue/provider state, not only a classification label.
- Revenue retains exact entity, month/calendar/currency/basis and provisional/closed status. Quotes retain instrument/exchange/currency/source time/session/delay; missing licensed fresh data is unavailable, not fabricated.
- Unrelated worker/sandbox failure cannot block a supported read. Authentication/audit/read computation is allowed and metered.
- Mounted Work must show the original independent result and incomplete state, current policy/calls/checks/costs and gaps. Logout, principal/root/Work switch, token refresh, revocation, offline/reconnect and delayed old-principal responses must not resurrect private output.

## Independent expected observations and retained failures

The exact reference returns each supplied state's value, all optimal choices and the input tie-selected choice. Policy mutations must reach the intended checker predicate: missing/illegal action, changed model/price/checker, omitted cost, bad probability, unsafe stop, erased obligation and fabricated ROI. Retain the original failed input, error, duration and subsequent affected rerun.

Owning E2E must observe real authenticated API, queue/claim/fence, worker, persistence, S4/compute consumer, S5 lease, applicable S6 boundary, independent result, S7 costs and mounted original Work. Final cold installation uses declared locks/assets in a separate checkout without donor dependency/build trees. A build, local algorithm proof or authority denial does not substitute for this chain.

All original W001–W060 remain in the finite manifest. Unbound/unrun work stays NOT_RUN. Software, exact checking, empirical usefulness, protected qualification, admission, activation, field, comparison and economics are separate.
