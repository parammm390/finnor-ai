# W3 concrete owning-boundary verification cut

This supplements, and does not backdate, `failure-model.md` and
`verification-manifest.json`. The failure model and independent original-derived
predicates preceded critical code. These executable drivers were written after
product code. No post-code unit tests are introduced. This is a public engineering
cut, not independently held protected qualification.

## Commands and limits

Run from the absolute `finnor-os` workspace, with Node 22.22.3 and the backend lock.
Each output directory must be new; failures and prior outputs are never replaced.

* `node --import=tsx scripts/postz/w3/verify.mts --output <absolute-new-directory>`:
  actual migrations, ordinary `finnor_app` without superuser/BYPASSRLS, signed
  bearer HTTP, S1/S3/S4/S5/S6 originals, canonical Work, physical queue claim,
  worker, independent checker and artifact; 120-second wall bound.
* `node --import=tsx scripts/postz/w3/native.mts --output <absolute-new-directory>`:
  the same path plus native S6 request compilation, independently generated
  disposable signing roots, real TLS conditional recipient, authenticated
  participant consent and reports, S7 and physical kill/recovery; 1,200 seconds.
* `node --import=tsx scripts/postz/w3/native.mts --invoice-challenge <0..7> --output <absolute-new-directory>`:
  a separate full-path invoice challenge. Even samples overbill once; odd
  samples split the excess across distinct invoices without increasing the
  original quantity. Revoke the provider's reporting protocol after refusal
  and require the historical liabilities to remain. This branch intentionally
  does not execute normal payment recovery, final S7 or mounted cases. It is
  not a replacement for the normal full run.
* `node --import=tsx scripts/postz/w3/native.mts --installation <absolute-install-root> --output <absolute-new-directory>`:
  run from that installation's own `finnor-os` directory. It must use installed
  API/worker/checker/scientific/frontend bytes and pass all nine mounted cases.
* Proof-driver typecheck: `node node_modules/typescript/bin/tsc -p scripts/postz/w3/tsconfig.json`.

Require at least 4 GiB free before starting; at most 6 GiB generated evidence.
No paid runtime LLM calls, real provider contact, genuine human time or purchases.
Source/runtime/lock/migration identities, original inputs, intended rejection
owner, observed outputs, first failures, duration and rerun command are retained.
Original business deadline and original parent resources are not replaced by a
local timeout or recovery grant. A seven-day assignment counts once.

## Registered predicates

1. Read-only Work access creates no request, queue job or effect (W004 slice).
2. A provider's own authenticated availability wakes compilation. Every original
   date/site/window/quantity/unit/criterion and dependency survives, all seven
   instances are checked, assignment count remains one (W025 software slice).
3. An unrelated principal and foreign tenant cannot read Work or its S1 original;
   the owner cannot consent for the provider. Generic S1 mutation cannot strip
   private identity; participant inserts require their real current protocol
   (W005 slice).
4. Native offer delivery is neither consent nor service. Booking remains blocked
   until exact-version participant acceptance, independent readiness and trial
   reports. Provider self-inspection is rejected by the role owner (W025/W028).
5. Authenticated provider delivery, independent observations and original
   acceptance remain separate. Native access retirement requires the original
   end. All controlled reports retain their limits and cannot establish genuine
   sensory, qualified safety or elapsed field evidence (W025/W032 slices).
6. No invoice settlement is inferred from scheduling. Kill the actual worker
   after the recipient's PATCH commits and before its response. Preserve UNKNOWN,
   original identity and capacity; recover by readback after lease expiry and
   broker restart with no second PATCH and no replacement allocation (W030/W051).
7. S7 has actual delivery-attempt compute and original-input projection records.
   Missing money prices and full cost coordinates stay UNKNOWN and prevent
   financial reconciliation. A controlled complete service does not complete
   the canonical Work as a field result.
8. Before new request/job publication, eight fresh cyclic originals fail at
   the original-input owner with HTTP 400 and unchanged S1 version/request/job
   counts. A nonempty acyclic original must instead be accepted as exactly one
   source version without a new request/job. That positive control is only a
   source-boundary proof: the cook journey's dependency vectors remain empty,
   so compiled nonempty-dependency execution is still unproved.
9. Single and aggregate overbilling fail against the literal original quote.
   Physical completion may remain true while financial reconciliation is false.
   Exact original invoices remain unreconciled after provider withdrawal.
   Refusal must produce no additional recipient PATCH at any identity, not just
   at a key computed by the producer. Normal recovery likewise permits no extra
   PATCH at another key.
10. Installed mounted controls must consume the emitted Next frontend through
    same-origin authenticated APIs. Hold an already completed real owner
    response, then exercise actual offline/online, root A–B–A, logout/principal
    A–B–A and authority revocation. Enter a nonsensitive unsubmitted draft
    through the actual textarea before these boundaries. Neither old rows nor
    old drafts may return before or after a fresh response. Participant tests
    wait for the exact current invitation set, revoke through the rendered
    control and observe actual wall-clock expiry. Historical receipts contain
    no operational disclosure. No response or UI state is fabricated.
11. An actual worker attempt creates S5 accounting with a digest, not its raw
    claim credential. Independently compare the actual queue-attempt token's
    SHA-256 JSON-string digest, inspect the actual signed owner-delivery origin
    and perform authenticated `obligations/budget-status` validation against the
    original allocation. Never emit the credential into proof output. The
    separate actual-512-charge replay/exhaustion trajectory is not yet
    implemented; do not replace it with fabricated SQL charges.
12. Two authenticated advances with identical original projection must execute
    as two distinct physical queue deliveries, each charged and metered, but
    reuse the identical S7 measurement record/event and original valid/knowledge
    times. Semantic request binding includes rights, dependencies, estimand and
    every payload field, not a newly sampled publication timestamp.
13. Read back the original canonical Work and existing programme occupations,
    not just the service panel. Completing transport workflows must never emit
    a premature completed Work event. Unknown full costs after operational
    completion retain Work in recovery and W3 in RECONCILING. Both fast and
    full runs retain and assert final queue health with no unfinished/failed
    tenant-local job. Native-009's zero exit did not check these predicates.
14. A fresh source packet must carry every immutable historical Git preimage
    actually read by its reused builder. Reconstruct the complete archived
    source tree and original commit without alternates, install only the
    packet's exact additional object population, retain each historical
    commit/tree identity and pass Git connectivity. The original retained
    migration comparison must still execute against that exact commit.
    Changing the reference, skipping the comparison or borrowing a donor Git
    object store is not a repair.

X1-named compatibility manifest is a reused owner format, not an X1 result.
W3 adds the actual production-registry worker entry and separate W3 checker,
closed local Node dependency copies, relocated scientific runtime candidates and
the emitted standalone Next frontend. The builder must refuse
a dirty source checkout or an existing output. It retains inherited engine
bounds as well as the W3 bounds. Actual build 002 exited 1 during locked native
dependency copying; D018 specifies its contained-alias correction and real
unsafe-link controls before the change. Native-library relocation,
the actual runtime dependency closure, frontend startup and installed-only
consumption are unverified. Having packer source is not a portable release claim.

The source packet must contain the complete archived Git tree and exact original
commit object, both lockfiles and hashes. Reconstruction must use only that
packet for source, create a standalone shallow repository without alternates,
install fresh lockfile dependencies, retain command exits and first failures,
then build and exercise installed W3 bytes. Cached package downloads are allowed;
copied donor dependency trees and donor source imports are not. A source-only
reconstruction receipt is not an installed or mounted result. No process in this
cut can issue protected qualification, physical truth or production authority.
