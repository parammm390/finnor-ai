## Domain and claim

Fixed, separately admitted finite component revisions are inputs, not things
the linker may repair or synthesize. The supported executable meaning is a
closed bounded typed transition kernel. A source digest binds bytes but does
not establish the meaning of arbitrary TypeScript, SQL or a provider.
Original S4/S5/S6 owner readers supply current facts. Their broader behavior
is not proved by this kernel. Missing external contract admission is not
missing implementation, and a missing adapter is not external custody.

State comprises every original component location and one copy of each shared
cell. Each cell has an original identity, finite domain, lawful observers and
an immutable/reservation/obligation/authorization/world/resource classification.
Duplicate aliases for one original cell are rejected. Legal initial tuples
are explicit, including their joint world correlation. Every original
transition is interpreted. Atomic simultaneous writes, rendezvous input/output,
may/must and internal failure steps remain explicit. Buffers, calendars,
delayed callbacks, locks and UNKNOWN must be represented as state, not erased.
The tool refuses unsupported expressions, hidden authority and over-limit
products. It never truncates a graph and calls the result complete.

## Whole-shape comparison and selected mechanism

1. Explicit coupled product: exact operational expansion followed by a finite
   safety/nonblocking supervisor. Retains real coupling; worst case is the
   full product.
2. Factored compatible interfaces plus abstraction/refinement: potentially
   smaller, but proving independent state factors and private-observation
   refinement adds another relation and can collapse back to the same product.

Select (1), the smallest complete supported mechanism here. The compatible
context is a checked sound subset, not a weakest or maximally permissive
environment. No compactness, novelty, inevitability or speedup claim follows.
The independent Python checker reconstructs the original operational product,
translation, context closure, all initial/transition discharge, nonblocking
ranks, replacement simulation and live bridge without importing producer code.

An environment represented by the context contract must offer its declared
must-input alternatives. It may resolve may alternatives and delay progress;
it cannot suppress an original component output or alter shared state outside
an original environment transition. Every reachable pair has a finite path
to completion or explicitly legal quiescence. This is existence of completion,
not eventual completion on every infinite schedule. Environment restrictions
and public-observation uniformity are explicit conditional cooperation.

## Native engineering contract

Implement concrete SQL-backed request/artifact/event/component/admission/use
adapters and the registered worker handler; no optional unbound owner ports.
Bind original Work/root/input/mandate/assignment, original S5 compute allowance,
capital reservation and outstanding S6 origins. Debits commit before physical
work; interrupted attempts retain their debit. Currentness is rechecked at
submit, claim, check, persist, admit, replacement use and effect handoff.
S4 consumes a checked declared contract for integration/replacement planning,
not a financial action. S5 present capacity and S6 dispatch/observation retain
their original authority. S8 admission is explicitly ordinary development,
never protected admission. S7 uses the actual assignment transport with
unmetered material costs retained. Shared registrations, SQL application,
API/mount/manifest/build changes require exact preimage-bound coordinator
requests. A patch is not an application or authenticated observation.

## Finite verification, frozen before product code

Freeze the 32 public structural families with eight fresh cases per family.
Each file contains actual fixed kernels, initial tuples, expected result and
an independent mathematical reason, not just a seed for an unfrozen generator.
The registration records useful-positive denominators before execution.
Run one bounded full sweep, retain every failure, and rerun affected cases
only for a diagnosed change. Require at least 95% useful supported positives
and every critical falsifier rejected for that public engineering sweep.
This builder-controlled sweep is not protected independent qualification.

Run process-to-process producer/checker/corruption/currentness/recovery
contracts and three physical kills of owned offline journal workers. Label
them LOCAL FILE evidence, not native queue recovery. The guarded native E2E
also contains all three actual-worker interruption steps, owner readbacks and
mounted reload, but must refuse here: no DB/Auth/migration/seed/listener/effect
authority exists. Do not run the stack launcher.

Run affected syntax/types/lint, existing read-only catalogue/workspace checks,
and full graph checks under the shared heavy lock, at most 4096 MiB. Refuse
unsafe dependency-install headroom. A separate minimal offline reconstruction
does not become an installed full application proof. Preserve original failed
doctor/toolchain/build logs and any preimage mismatch.

## Expected value and comparison

Useful output is a nonempty, original-transition-closed context with explicit
conditionality, independently checked correspondence and a real reachable
live-state bridge or an actionable original counterexample. Conjunction of
three component checks or a disconnected toy pipeline is insufficient.
Credit full intended X/Y, X2 composition, X3 installed invariants, Y5 proofs
and ordinary model checking/Pacti/OCRA as equipment. Five alternating public
diagnostics may measure explicit product/context costs but are not an equipped
increment. Extraction, exploration, translation, checking, integration,
replacement, invalidation, recovery, install, failed work and human costs are
all charged or explicitly unknown. Financial outcomes and 100x are unrun.
