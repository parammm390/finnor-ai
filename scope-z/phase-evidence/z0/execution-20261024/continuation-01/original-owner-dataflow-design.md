# Original-owner use, source-grounded design before implementation

The existing institution vocabulary is exactly `open_workstream`,
`create_deal_request`, and `record_finding`. Its canonical observer, not an X2
prediction, establishes completion. A learning grant never dispatches a duty.

The old consumer records CONSUMED before validating the P1 job claim and its
return value is ignored. It also skips currentness on a previous CONSUMED event.
Both call sites must change. Initial preparation gets a post-claim pending/S6
fence. Actual native continuation computes the value it passes to the existing
action bridge after the real P1 claim, not at queue intake.

Supported materialization is deliberately closed: every leaf of the complete
frozen business payload must be representable as an evidenced text, enum,
boolean, or nullable model state field with its exact dotted path. Arrays,
numbers, unsupported scalar types, absent fields and ambiguous bindings are
typed direct fallback, not newly inferred meaning. Search remains the canonical
64-node/8-step composer. A real retained independent original observation is
the initial state, explicitly projected through the original schema. No
conditional branch may manufacture an argument. At least one business value
must actually change through an evidenced assignment. Every computed leaf is
copied from the final checked expected state into the actual owner argument.
The existing complete frozen-intent comparison must still pass.

This is model-relative argument computation, not a claim that a learned
external operation is the native business operation or that any physical
postcondition has already occurred. The original action bridge still performs
its own current authorization, eligibility, exact action-ID and plan checks.

Each physical materialization charges the existing original S5 PREPARATION
phase with a fresh physical invocation UUID before computation. Its charge
commits separately, so failure cannot roll its cost back. Original aggregate
remaining capacity/deadlines remain unchanged. Native continuation's existing
compute meter includes this work; money remains UNKNOWN.

Every use, including redelivery, revalidates the original owner, actual live
job/token/fence/lease/generation, pending learning, S6 uncertainty, immutable
acceptance/model/check, current source/code/schema, operation validities and
current original governed profiles. RUNNING is accepted only with that exact
original delivery, never as a new acquisition admission shortcut.

A MATERIALIZED artifact alone is not CONSUMED. The actual original bridge
receives the computed payload and its materialization reference in the existing
authority context (which grants no new authority). A later read of the real
canonical DomainAction must match that reference and the complete frozen
meaning before useful-use evidence is recorded or projected. A historical trace
without this native row is not useful use. Physical effects and independent
canonical observation remain separate gates.
