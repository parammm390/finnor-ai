# Additive native correction requests

These do not replace the immutable original nine-patch packet. Generate a fresh
packet with `finnor-os/scripts/project-z/z3/build-native-corrections.mjs`.
Each request names exact preimage and postimage SHA-256 and Git blob IDs.
Only the coordinator may apply shared sources. A preimage mismatch is a stop,
not permission to overwrite another lane's changes.

S5 adds a same-transaction option to its existing validators and physical
charge owner. S4 adds a concrete owner entry for the bounded native consumer.
The mounted panel adds an existing-original-Work submit control and displays
remaining original P1/S5 units and observed finite memory. No new catalogue
generator change is requested; coordinator review 06 owns CONTROL/invalidation.

No request executes a migration, provisions anything, authorizes DB/Auth,
dispatches an effect, publishes externally or qualifies a protected mechanism.

The additive `v3/` packet supersedes `v2/`, which is retained as-run evidence.
Its fourth request prevents the actual shared queue from renewing or completing
an already expired physical lease. Only the coordinator applies that request.
