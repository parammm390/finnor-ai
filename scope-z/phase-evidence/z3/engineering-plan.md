## Pre-code failure model and expected-value contract

The original public arena, not a producer-selected subgraph, defines the
transitions, initial set, safety, environment justice and recurring goals.
Controller predecessor is existential, environment predecessor universal.
Deadlock is losing unless the original input explicitly declares an absorbing
terminal with its actual labels. No fairness means the unconditional set V.
The safety kernel precedes liveness; unfairness cannot excuse unsafe reach.

Credible failures include dropped environment edges, partial initial coverage,
wrong fixed-point polarity/termination, arbitrary rather than complete fixed
points, malformed or insufficient memory, illegal action/update, a fair bad
non-bottom SCC, safety only checked under fairness, fairness sabotage, impossible
assumptions, hidden-state conditioning, source/rights/code revision reuse,
invented resource renewal, permanent UNKNOWN erased by restart, stale fence
publication, duplicate continuation, and lost S6 identity/deadline/cost.

Expected values come from the original temporal contract and independently
implemented exhaustive strategy/product checking on a registered small finite
population. The primary proof is the whole reachable strategy-memory graph,
including every cyclic SCC after each goal is removed. Every reachable prefix
must still permit a fair continuation for an accepted nonconflicting candidate.
An ordinary GR(1) win alone does not establish complete nonconflicting synthesis.
An initial outside the independently checked complete ordinary region permits
ordinary infeasibility; a conflicting extracted strategy permits UNKNOWN only.

Required negatives include the eleven named PRD fixtures, exact input,
edge/goal/policy/memory/currentness mutations, unauthorized identity, finite
resource and deadline exhaustion. Positive is controlled recurring internal
readiness/reconciliation, not perpetual finance. GF is not bounded latency,
non-Zeno execution, or completion of each individual request.

## Whole-shape options, before implementation

1. Explicit bounded GR(1) region iteration with full iterants and deterministic
   finite-memory extraction through an equivalent three-priority parity monitor.
   An independent original-arena checker recomputes the complete relation,
   reconstructs the memory product, checks safety, every fair bad cyclic SCC
   and prefix nonconflict. Native adapters keep the existing Work, job/fence,
   S4/S5/S6/S7/S8 and P7 owners. No new mathematical dependency.
2. Symbolic/abstraction-assisted synthesis with an explicit original checker.
   This adds a BDD/SAT dependency, abstraction coverage/lifting proof and native
   packaging without reducing the locked 256-state bound. Any lost original
   successor would invalidate it. There is no observed scale need for it.

Choose option 1, the smallest complete bounded shape. Memory is at most the
product of two assumption and two goal counters. Bound all loops, bytes,
checker subprocesses and runtime resources. Ordinary complete region evidence
and actual strategy nonconflict remain separate claims.
