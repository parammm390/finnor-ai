# X1 pre-code failure model v1

Written before critical compiler/checker code. This is an independently specified engineering failure model, not proof of correctness or protected oracle custody. The accepted native plan, original goal and profile remain binding.

| Family | Credible failure | Required behavior and independent evidence |
|---|---|---|
| Source authority | Foreign source, revoked access, fabricated provenance, sensitive personnel without consent | Reject access/binding; retain authorized coverage gaps. Original source/rights/principal state, not candidate assertions. |
| Transport coverage | Missing page, repeated page/cursor, out-of-order update, truncated file, tombstone, malformed archive, oversized row/zip expansion | Bound acquisition/decoded expansion; retain raw bytes/order/coverage; no silent completeness. |
| Injection | Email/document/HTML tells compiler to ignore policy or disclose data | Treat bytes as evidence only; no grants, egress expansion, checker/objective edits or hidden-oracle access. |
| Identity | Same names, overlapping staff, reused vendor IDs, fund/deal confusion, source-local ID treated globally | Require explicit scoped identity witnesses; preserve alternatives. Wrong entity candidate must reach identity checker. |
| Relations | Wrong edge direction/type, cross-tenant/fund relation, omitted material relation | Compare independent raw/owner relation population including omissions. No name-only join. |
| Time | Date convention ambiguity, wrong timezone, knowledge before availability, impossible ordering, deadline changed on retry | Exact chronology/valid-time/knowledge-time predicates; unknown ambiguous dates; original contractual deadline preserved. |
| Units/accounting | USD20 vs USD200, thousands vs units, currency/period/entity/basis mismatch, sign error, plausible wrong balance | Bind complete quantity context, use exact decimal/rational arithmetic where relevant; independent accounting checks never prove identity by themselves. |
| Normative rules | Historical practice/silence/emailed exception promoted to mandate/approval | Require current explicit mandate/policy provenance and authority. Produce exact missing decision; preserve independently supported work. |
| Contradictions | Lower-authority contradictory record silently discarded, correction overwrites old fact/effect | Retain counterevidence/bitemporal history, withdraw affected readiness, reevaluate rather than rewrite. |

| Resources | P1 counters masquerade as S5, two Works double reserve, descendant/retry gets fresh budget, cancellation releases outstanding exposure | Actual serialized S5 reserve/consume/currentness/charge/release under original parent. Independent row/occupancy evidence. |
| Currentness | Rights/source/mandate/personnel/method/operation/schema/runtime changes between checks and dispatch | Six checks and atomic claim/publication/use fences; sound minimal dependency closure, preserved unaffected work. |
| Concurrency | Stale job publishes over revised/cancelled head, A→B→A late response accepted, duplicate delivery changes body | Generation/fence and complete request digest; no stale publication or cross-scope restoration. |
| Native completion | 202, executor success, receipt/toast or row existence mistaken for full postcondition | Independently reread every specified canonical Request field under exact identity. Creation is not fulfillment or approval. |
| Unknown effect | Worker dies after mutation before ack; restart allocates fresh effect or assumes provider idempotence | Same obligation/effect/grant/deadline, UNKNOWN retained, read-only reconciliation first; no duplicate effect. |

| Work privacy | Same-ready user switch, denied refresh, delayed mutation/recent list/world/thread response leaks old private output | Synchronous scope hiding, monotonic generation, abort and callback fences; actual mounted adverse evidence. |
| Cost | Retries/caches/checking/human work omitted/double counted, unpriced record counted as zero, RSS claimed complete memory | Stable charge IDs and actual S5/S7 writers. Preserve explicit unknowns and meter coverage. |
| Qualification | Ten renamed fixtures, eight labels over JSON, expected outputs derived by producer, hidden ledger accessible | Structural/protocol/process diversity, separately administered frozen denominator/custody; development-only absent protection. |
| Clock/scoring | Accelerated replay counted as elapsed soak, only successes denominated, critical missed duty averaged away | Separate replica/live clocks, all original assignments and critical veto, per-environment thresholds. |
| Packaging | Wrong peer source through symlink, builder-only checker, old job broken, migration loses history | Own workspace resolution, final installed byte identity, old/new job/restart/data-preserving upgrade and standalone reconstruction. |
| Measurement | Collector wrong column/du race causes false product failure/pass; observer timeout restarts work | Fix actual observer, retain raw error, diagnose process/SQL/lease first; do not alter episode deadline. |
| Resources/host | Disk exhaustion, expensive repeated build, unbounded search/checker or transient children unmetered | Frozen bounds, source work below live floor, explicit NOT RUN/INCOMPLETE, one final stable build, no peer deletion. |

## Adverse cases frozen before implementation

Checker challenge set C contains separate correctly scoped candidates for wrong entity, wrong currency/unit/magnitude, impossible chronology, wrong deadline, unsupported normative rule, suppressed contradiction, omitted obligation, stale revision, unauthorized operation, foreign tenant/source/principal and forged check. Every record states which guard must be reached; earlier unrelated refusal is not success.

Physical D/E faults use the actual worker and durable SQL/action boundaries. Test fixtures may coordinate locks/process death externally; no test-only production bypass. Original accepted children, grants, deadlines, costs and UNKNOWN effects survive.

### Registered owner case B-ledger-correction

Before adding this E2E case, freeze a correction from USD 20.00 to USD 25.00 for
the same Deal, period, unit, accounting basis and ledger record. The standing
Request-creation rule depends only on its separate work-tracking trigger and
mandate. Credible regressions are a stale positive read, failure to queue the
actual P7 update, replacing the original resource parent/deadline, failing to
publish the independently checked correction, invalidating the unrelated duty,
duplicating its already observed Request/effect, or rewriting its prior proof.

Use actual Core version append and a superseding ordinary source-grant version;
keep its purpose, principal, source class, validity interval and all other source
handles. Observe the registered physical update/compiler/native workers and
canonical ending rows. No direct call to the update handler or candidate edit
is permitted. This case covers the ledger correction and unaffected continuation
subset of B; the complete PRD fixture and remaining B variants stay required.

The independent oracle contract defines expectations and preservation. Boundary bugs need a pre-fix failing regression at their owning boundary. No post-code unit tests. Source changes following a failed proof retain the original run and rerun only affected proof plus necessary regressions.
