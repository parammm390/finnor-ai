# Named finite owner verification

The repository verifier now dispatches the actual authenticated owner driver with
a scrubbed environment and the original frozen limits. A named case pass proves
only that case. It does not pass an entire A–H group, installation, qualification,
admission, activation or economics. Raw source/runtime/schema/profile/oracle,
HTTP/queue/worker/checker/owner/Work/ending evidence and failures remain in the
fresh private owner directory named by run.json.

Run from the repository root with a fresh direct child of the registered private
evidence root. Never reuse, overwrite or remove an original failure directory.

| Stage | Required --case value | Owning boundary |
|---|---|---|
| owners | one-duty | Actual complete authenticated raw-to-native slice |
| owners | 128-duty | Original full 128-duty population and bounded native Plans |
| owners | heterogeneous | Eight classes/twelve direct original-byte protocols |
| owners | canonical | Fourteen existing canonical kinds and actual attachments |
| lifecycle | material | Actual automatic ledger correction and immutable lineage |
| lifecycle | recovery | Physical compiler death, UNKNOWN and same-parent resume |
| lifecycle | contention | Actual shared S5 refusal and cancellation |
| lifecycle | unsupported | Supported native effect beside exact unsupported duty |
| lifecycle | cancel-observed | Stop future standing continuation, preserve effects |
| mounted | mounted | Existing real login/Work/revision/private-state browser proof |

Example command; its exact case is selected explicitly:

```sh
node finnor-os/scripts/frontier5/x1/verify.mjs --stage owners --case one-duty --evidence /absolute/registered/private/evidence/fresh-owner-wrapper
```

The mounted case additionally requires an actual authorized browser observer.
The private fixture contains disposable local credentials; keep its bytes out of
public output and source. Use the existing login form and mounted Work, observe
canonical completion markers, capture AX/screenshots, and submit the exact
scope-bound observer receipt. A timeout, queued request or incomplete observation
must not be called a mounted pass. The observer does not reset any deadline.

Offline kernel/static/qualification-contract commands retain their original
scope. Final installed, diagnostic, handoff and complete scrutiny stages remain
required until their own drivers/evidence exist. The verifier refuses unsupported
stage/case combinations and never converts a missing live stage into a pass.
