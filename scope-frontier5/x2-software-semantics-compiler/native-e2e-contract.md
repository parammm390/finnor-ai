# Native application verification, before the driver

This extends the frozen portal oracle and requirement/failure manifest. It is
end-to-end verification, not post-implementation unit tests. The candidate
worker receives only native Work, current authorized profiles and exposed
application surfaces. The evaluator retains the private portal directory,
withheld objective and journal. Same-UID processes are not a custody sandbox.

Primary owner boundaries:

1. **Migration and ordinary roles.** A fresh PostgreSQL instance installs the
   immutable predecessor migrations, then 0191 through the actual migrator.
   A replay applies nothing. The application and physical worker logins remain
   non-superuser/non-BYPASSRLS. A no-scope application read cannot see jobs or
   application artifacts. This catches missing SQL prerequisites, privileges,
   replay and queue authority regressions that source type checks cannot.
2. **Authenticated native request.** Actual signed bearer verification, employee
   lookup, Company Brain route, Work input and S4/S5 registration are used.
   Anonymous, bad-signature and other-principal calls must not create a session.
   Identical replay keeps one original reservation/session/deadline. This owns
   transport and authority coverage; fixture-supplied receipts are forbidden.
3. **General acquisition.** A separate process uses the real worker registry,
   queue claim, compute lease, provider, S6 and independent readback. Two
   authorized demonstration records establish the four distinct portal
   transitions. MODEL_READY requires the actual independent accepted check and
   current operation validity, with retained original observations and charges.
   The withheld objective is released only after the retained model is frozen.
4. **Fresh model consumption.** A different canonical Work and fresh record use
   S4/P1 composition and S5/S6 under the unchanged original reservation and
   deadline. The independent oracle's exact objective, not any product
   prediction or response toast, determines success. Every actual request must
   join its original obligation, native effect, action and receipt. The 18-digit
   decimal and currency/entity/unit/date/basis must survive without coercion.
5. **Fault and validity continuations.** Subsequent declared runs use the same
   driver and frozen oracle for response loss, physical before-ACK SIGKILL,
   opaque observation, rendering relocation, semantic drift, cancellation,
   grants, siblings and resource exhaustion. Each runs at its owning boundary.
   Unselected families are NOT_RUN, never inferred from the positive run.

No special product flags, mocked owners, generated admission receipts or new
test-only exports are needed. Independent administrator controls belong only
to the driver. Raw runs retain source pins, immutable oracle hashes, actual
SQL/process/API observations, failure timing, private custody paths and costs.
Failed attempts are kept. Reruns create separate registered disposable episodes;
they do not renew or replay an already accepted business episode.

The command is `node node_modules/tsx/dist/cli.mjs scripts/x2/run-native-e2e.mts`
from `finnor-os`, with a new absolute `FINNOR_X2_EVIDENCE_DIR`. The declared
surface is selected by `FINNOR_X2_TEST_SURFACE=api|ui|hybrid`. UI and hybrid
require an owned legitimate browser endpoint under the provider's actual
configuration. Development proof does not confer protected or production
authority, external population qualification, billing coverage or a multiplier.

## Observation age and owned lifecycle meters

The retained 080 chronology shows 21 pre-existing native-event references
committed after the fresh predecessor observation, within a 16,156ms S6
append-timestamp span. It does not identify HTTP/fsync/SQL/scheduling latency.
Prepare existing reference backlog before a new step's actual observation.
Keep all mandatory delivery, current grant/Work/model/resource checks and
newly created request references afterward. Never refresh an observation's
timestamp, replace a possible effect, extend 30-second freshness/5-second
physical limits, or grant a new deadline. The existing 96-reference native
backlog scenario must retain original digests, one delivery per record and
fresh independent business, plus real egress refusal controls.

Measure preparation before observation and actual P7 invalidation/rendering
maintenance in their existing owners. CPU/wall slices inside a delivery are
nested, not additive charges; process lifetime RSS is not aggregate memory.
Successful rendering maintenance must charge its original S5 parent before
publishing a replacement binding. Invalidation must still fence the smallest
sound closure when spending is unavailable; its measured overhead stays
attributed to the original parent, never erased or claimed free. Billing,
human work and aggregate simultaneous memory remain UNKNOWN.
