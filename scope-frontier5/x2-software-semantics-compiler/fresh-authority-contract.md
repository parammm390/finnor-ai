# Checked fresh authority handoff, before implementation

A frozen learned transition is knowledge about an observed application domain,
not an authorization token. A fresh record may have a separately issued grant.
Equality with a demonstration grant must not be bypassed or silently replaced.

S4 must retain an immutable fresh-role binding before enqueueing execution.
It binds the already checked model/check, original parent/reservation/deadline,
new canonical Work/input, exact fresh record/entity/application/account and
current native principal/root/rights. Every supported role maps to one exact
current governed profile. The original retained grant preimage, not an updated
demonstration profile, supplies the old identity.

This development domain permits a new grant/profile revision only for the same
native employee, native application account, external acting principal,
application/account and role. Changed principals or roles require a different
admitted domain and remain blocked here. Current authorized record/entity scope
and external grant may differ. Native and external rights are both rechecked
before wire; the historical successful grant confers neither.

The handoff adds no deadline, budget, protected admission, professional meaning,
approval or commitment authority. A supplied profile list only selects existing
governed profiles; generated model/composition code cannot mint or edit one.
Later profile/credential/grant drift fences the handoff. External revocation
also fences actual observation and dispatch through the source context.

Rendering/observer revalidation compares structural semantics after removing
only explicitly checked profile identity, never request/resource templates,
schema/semantic revisions, parameter lowerings, method or observation coverage.
Exact fresh private binding and observer references enter each S6 obligation.
The learned artifact remains unchanged; relocated locators are not authority.

The native positive portal run must freeze the model before held-out release,
then consume the newly issued grant under the same parent. Wrong principal,
account, role, fresh target, current profile and changed-after-binding cases
must reach the intended owner/physical fence. The independent portal journal
and native effect/receipt joins, not this document, determine acceptance.
