# Typed owner slice, before implementation

## Boundary and meaning

Use the existing Y5 discovery, job, event, capsule and use ledgers. Keep the
released allocation command unchanged. Add distinct `submit-total` and
`consume-total` commands. Existing read, list, cancel and P7 invalidation retain
their authorization and history rules. No alternate queue or admission path.

The specification is resolved from the current authenticated specification
Work, never from the submit body. S5 owns a separate, read-only typed task
instance recorded in another authenticated Work input:

```
{schema:"finnor.s5.total-task-instance.v2", specificationRef, values:[...]}
```

`specificationRef` must equal the resolved immutable specification source.
`values` are canonical exact integers, at most 128 items and 512 digits each.
They describe an explicitly recorded task, not verified field measurements.
An instance request names its Work, not replacement values or a replacement
algorithm. This task does not inherit an allocation certificate or assert an
S5 policy-bundle optimum. Its quality is the independently expected typed
least-initial-state statement. An original-owner reference check also checks
all prefixes, including the empty prefix, under that task's meaning.

## Discovery provenance

Submission obtains the server's current complete authenticated-principal S5
census. At least two distinct model-accepted episodes are required. Retain every
request, refusal, cost and unknown record, not a caller-selected head. All
request scenario-term sequences become bounded development probes, alongside
the original typed task and fixed generic grammar probes. This projection is
development data, not an equivalence between S5 allocation objectives and the
new typed task. Refuse an oversized complete projection rather than truncate it.
The capsule binds the census digest and the original-principal selection rule.
Local model certificates and public specifications earn no protected credit.

### Development separation correction

Integration review found both owner's E2E task vectors among the proposed
generic probes. The second task must remain a future-use check, not a supplied
development example. Generic probes are instead the complete length-zero,
length-one and length-two lists over `{-1,0,1}`. The explicit original task and
every bounded scenario sequence remain development inputs. Reserve the
remaining probe capacity before projecting; refuse overflow without selecting
convenient records. The owner E2E checks that its future vector is absent from
the retained discovery inputs.

## Lifetime, physical execution and publication

Use the existing claim token/fence/delivery attempt and serial native lease.
Recover only a durably accepted capsule and recheck its exact owner target.
Re-resolve the specification, original task, census visibility and historical
content before publishing. Preserve attempts and physical UNKNOWN costs.

The campaign deadline bounds discovery. It is not the lifetime of an all-size
theorem. A use gets no more than the existing 28.5-second HTTP invocation and
30-second native bound, and consumes the original finite use allowance.
Current specification/policy, source/runtime, rights and task Work still fence
each use. Later S5/S6 activity does not by itself erase a mathematical theorem;
its historical census must remain intact and visible. Cancellation and P7
invalidation still stop new uses. Missing assets never trigger hidden rebuilds.

Reads separate lightweight status from explicitly requested capsule evidence.
Do not repeat full proof capsules in history responses. Withhold bound payloads
when any original source authorization is unavailable. Refuse applying the v1
allocation evaluator/admission profile to a v2 capsule.

## Prewritten end-to-end oracle

`verify-total-owner.mts` creates two real S3/S4/S5 accepted model episodes for
one authenticated principal, plus a contradictory refused sibling. It records
the typed specification and task in native Work inputs, calls the actual HTTP
submit, runs the real queue claimant/worker, reads the capsule lazily, and uses
the same kernel-checked definition on two distinct Work-bound instances.
It checks the complete adverse census, all-prefix reference results, idempotent
replay, no caller definition/values, another principal's denial, source change,
P7 invalidation, durable finite counters, no S6 effects or reservations, and
unadmitted public status. Its original failed run and every correction remain.

This slice does not establish installed-byte/UI operation, OS isolation or
aggregate-memory enforcement, independent semantic/trust/custody acceptance,
full Markov reasoning, protected unseen-family credit, complete comparative
accounting, practical improvement, or S7 economics. Those remain separate work.
