# Y5 failure model, written before discovery/checker implementation

This is an acceptance specification, not evidence that the predicates pass.
Domain/commands will be frozen after the full governing sources and real
owner interfaces are resolved, before qualification exposure.

## Mathematical and discovery failures

- Examples, finite enumeration, a recurrence or an atlas are relabelled a
  uniform theorem. Inspect actual quantifiers and original definitions.
- A desired conclusion becomes an assumption, the domain is contradictory
  or empty, or a size cutoff makes larger cases vacuous. Require independent
  statement binding and nonempty witnesses at multiple sizes.
- A human/library supplied successful lemma, algorithm or proof is called
  autonomous discovery. Retain the grammar, candidate origins, complete
  attempts/counterexamples and reused assets separately.
- Search changes the original objective, feasibility, rounding, ties,
  liabilities, structural family or declared resource model after failure.
  Bind original specification and owner semantics before search.
- A proof establishes only value, not a feasible returned decision,
  termination, quality or the declared cost bound. Each is a separate
  required obligation. Arithmetic counts are not bit/wall-time bounds.
- A solver/oracle hides exponential work or trusts unchecked answers.
  Inventory and charge every subroutine and conversion.
- Public supplied-answer mechanics are counted as protected discovery.
  Keep the Markov fixture and twelve unseen-family record separate.
- Failure to find/prove a method is called infeasibility. Return UNKNOWN or
  INCOMPLETE unless there is a checked infeasibility basis.

## Kernel, trust and implementation failures

- Exit zero, generated prose, a producer label or a digest stands in for
  exact expected-type/kernel acceptance. Independently inspect definitions,
  proof object, theorem identity, transitive imports and axioms.
- Sorry/holes/custom axioms/native unchecked evaluation, shadowed
  definitions or changed imports/kernel manufacture acceptance. Challenge
  the intended kernel/type/trust boundary, not an earlier parser guard.
- Inventing an allowlist or banning ordinary library axioms substitutes for
  actual S8 trust policy. Mathematical validity and approved trust basis
  have distinct statuses; absent policy cannot be self-approved.
- Abstract integer correctness is applied to changed float/fixed-width
  code, rounding, ties or liability handling. Bind actual executable code,
  translation route and runtime; record compiler/VM/OS assumptions.
- A parser/serializer silently loses precision or overflows. Use exact
  canonical values and independently check original-space results.
- An implementation/source mutation keeps an old green receipt. Recheck
  source, definitions, toolchain, numerical and admission identities.
- Similarity substitutes for a structural applicability proof. Recheck all
  prerequisites for every use and withdraw only the affected claim/use.

## Original-owner refactor failure, review refinement before repair

- A shared input resolver catches every `STALE_INPUT` exception and changes
  an existing source/rights refusal into an ordinary clearing response.
  `currentPins` has its own original `STALE_INPUT` refusal. Preserve its
  propagation. Only the complete-resource-registry mismatch that the
  original clearer explicitly returned may become that same typed result.
  Verify the registered original S5 source/rights and clearing end-to-end
  cases. This compatibility repair is not a new permission or solver.

## Security, durability and responsibility failures

- Unauthorized episodes/private facts are mined or protected answers are
  exposed to candidate search. Resolve lawful accepted inputs through S1;
  keep evaluator custody outside candidate control.
- Generated search can read credentials, change checkers or access network,
  run unbounded children or exceed parent resources. Bound permitted syntax,
  processes, bytes, CPU/memory/time/storage and filesystem access.
- A capsule is saved but the real owner still runs an unrelated method.
  Require positive authenticated API -> durable queue/claim -> actual
  discovery/kernel -> persisted capsule -> actual selected algorithm ->
  independent original result -> S4/S5/S6 boundary -> mounted Work evidence.
- Ordinary CHECKED or disposable admission becomes protected admission,
  activation, consent or capital. Preserve existing typed S8 and S6 guards.
- Cached currentness bypasses changed rights, mandate, specification,
  implementation, trust, input or reservation revisions. Fence submission,
  claim, acceptance, publication, selection and consequential use.
- P7 revocation erases immutable history or unnecessarily invalidates an
  unchanged abstract theorem. Distinguish theorem, correspondence and
  current-instance applicability.
- Duplicate/stale delivery, cancel, lease expiry, physical worker/kernel
  failure or contention creates a second episode/grant/effect. Inspect real
  claims/fences/processes, retained costs and outstanding obligations.
- Fallback is a flag/mock or receives a new deadline/grant. Name and execute
  the compatible existing callee using the remaining original envelope.
  If absent, retain the exact unsupported/unknown/checked-incumbent result.
- UNKNOWN settlement disappears through restart or theorem acceptance.
  Read authoritative S6 obligations and never retry a real effect here.
- Work/root/principal switch, logout, token refresh, offline/reconnect,
  revocation or a delayed old response resurrects private output.
  Exercise mounted controls and authenticated persistence, not CLI-only UI.

## Delivery and measurement failures

- Build-time assets/cache are missing from final API/worker/runtime or a
  native dependency has the wrong architecture. Exercise final emitted
  bytes and declare actual host/guest/tool assets.
- A source-only replay or shared donor dependencies are called installed
  reconstruction. Use independent source objects, lock installs and declared
  secure/cache assets, then recheck proofs and the bounded owner path.
- Tests compare producer output with itself, copy admission receipts, miss
  their intended guard, or replace an exact theorem with finite checks.
- Failed attempts, unstarted families, costs, fallback, preparation, storage,
  human work or unchanged equipped comparators are omitted from the gain
  denominator. Retain all outcomes and explicitly named meter gaps.
- Y5 on/off is called a qualified comparison with completed X. The latter
  requires an immutable qualified B_X_release and matched equipped actors.
- A local theorem is called operational/economic 100x or owner wealth.
  Keep all protected, admission, activation, operational and S7 horizons
  separate. Never wait for field horizons inside this coding session.
- Disk pressure, host sleep or observer timeout is used to weaken a
  predicate or reset an accepted deadline. Diagnose actual cause, preserve
  failed runs, clean only task-owned disposable assets and rerun affected
  proofs on the changed cut.

## A4 native-parent-loss refinement, registered before guardian code

The original in-process timer dies with its worker. A detached Lean process
could then outlive both that timer and its logical claim. Cancellation tests
with a living parent do not establish worker-loss safety.

An independent, source-pinned Node guardian must own each Lean deadline,
output limit and physical close. IPC disconnect must kill the entire Lean
process group, await close, and retain a receipt without a live worker.
Account for missing start messages, spawn failure, lost IPC, parent death
before/after spawn, guardian failure, output overflow, cancelled currentness,
receipt-write failure and completion races. Unknown physical completion is
not a successful close witness. This does not establish OS sandboxing,
aggregate memory enforcement or safety after simultaneous guardian/host loss.

## Installed clone primitive refinement

The first real installation attempt observed Node's
`COPYFILE_FICLONE_FORCE` failing with ENOSYS on this Darwin runtime, before
compilation. Use the host's clonefile primitive instead, never silently fall
back to a multi-gigabyte full copy. Reject unsupported files, cross-device
cloning, changed source bytes and foreign resolution. Retain the failed output.
The clone helper must preserve links without following them; installed link
relocation and final no-escape inventories remain separate mandatory checks.

## Mounted typed Work refinement, before UI implementation

- Canvas focus changes only presentation preferences while the actual
  CanvasInstrument waits solely for IntersectionObserver. A visible instrument
  can remain unopened if no observer callback arrives. Explicit product focus
  must admit the instrument directly, without a timeout or fixture DOM click.
  The prior report records visible geometry and no animation frame; the cause
  of browser frame starvation remains unknown, not repaired by this change.
- A typed specification is guessed from labels or a supplied program. Resolve
  it through the authenticated specification endpoint, render its actual
  definition, immutable source and acceptance separately, and treat UNAVAILABLE
  as unavailable. Preserve the allocation v1 command and controls.
- Typed discovery/use sends caller values or consumes the specification Work
  as its own task. Require a separate recorded task Work ID and transmit only
  its reference. Show the exact owner-returned integer and count, without
  claiming an allocation optimum, economic gain, admission or effect authority.
- Every status poll downloads proof objects, or expanding a disclosure merely
  reformats a previously downloaded capsule. Poll lightweight reads; evidence
  must require an explicit owner read with includeCapsule/includeHistory.
- Polling overwrites a real draft, a late evidence response survives a Work
  switch, or rights loss leaves private forms/results on screen. Fence all
  responses by authenticated scope and selection; preserve drafts only while
  that scope remains authorized. Discard old requests on scope cleanup.
- Stopping local observation is mistaken for server cancellation. Keep the
  real cancel action and uncertain idempotent retries explicit. Do not silently
  cancel durable discovery merely because the user navigates away.
