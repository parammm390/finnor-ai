## Accounting and authority boundaries

- A structural refusal can avoid starting Lean while still charging the
  worker/compute lease and source reads. It is not a zero-cost operation.
- A killed or lost worker's prior physical cost can be unknown. Reuse of an
  accepted proof does not erase that cost or renew the original deadline.
- A durable STARTED use is not automatically run again. A completed use's
  immutable original deadline also bounds later independent oracle work.
- API/native deadlines, one local lease, 2-GiB Lean allocation settings and
  3-GiB build heaps are not an OS sandbox or a measured/enforced aggregate
  16-GiB host cap. Scratch and full host-loss qualification remain open.
- Source-object export, fresh npm lock installation, declared native-asset
  reuse, numerical reinstallation, installed execution and mounted execution
  have distinct evidence. A copied-asset build does not close reconstruction.
- Public development repetitions contribute no protected discovery/admission
  credit. Custody, twelve unseen families, eight accepted capsules, two new
  structures and the arbitrary-horizon Markov diagnostic remain open.

No result here authorizes production activation, real effects, remote writes,
protected promotion or a financial/economic claim.
