# Same-meaning recurring typed tasks

Registered before implementation. Candidate B and the generic search remain unchanged.

## Predicate and failure model

Discovery requires two distinct S5 model-accepted task Work inputs with the exact
resolved specification source, definition, and acceptance policy. Allocation
certificates are context, not typed-task acceptance. Every matching typed request,
including refused and UNKNOWN results, contributes its actual input sequence.
Retain the entire original principal census without filtering adverse records.

Falsifiers are allocation-only or one-task admission; caller-supplied values,
answer, or acceptance; forged or missing request/result/cost siblings; different
specification source, definition, policy, or task revision; revoked rights; foreign
principal access; census drift; expired original deadlines; unsupported safety
bounds; arithmetic, count, time, evaluation, or retained-byte exhaustion represented
as UNSOLVABLE; an omitted empty prefix or smaller candidate; silent truncation at
64 examples or 12 values; baseline answers sent to generic search; and the future
held-out vector `[-4,2,-3,8]` entering development data.

## Owner reference and qualifications

The public `record-task-episode` command accepts only root, specification Work ID (`workId`), task Work ID, and
idempotency key. S5 resolves current authenticated immutable Work inputs itself.
The reference derives a necessary lower bound from supported affine comparisons
in the declared safety expression. Everything below that bound violates
empty-prefix safety. It enumerates every integer from that bound, interprets all
prefixes, and accepts the first feasible candidate with reconstructible rejected
candidate witnesses. Unsupported expressions refuse; resource exhaustion is
UNKNOWN. This is a finite original-owner model reference, not the discovered
recurrence, an all-size theorem, business completion, field measurement,
independent qualification, protected credit, a reservation, or an S6 effect.

Record measured wall time and evaluator counts, with money, human time, and peak
RAM explicitly unknown. Existing immutable S5 experience storage is the only
episode ledger. Original rights, policy, source, Work, census and temporal fences
continue to apply.
