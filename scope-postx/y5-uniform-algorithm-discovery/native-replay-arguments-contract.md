# Fail-closed native replay arguments

Registered before the argument guard. The pinned LeanChecker source treats
flags-only input as an anonymous module prefix. Its normal replay also selects
descendant modules. Never run `leanchecker --help` or `--version` as a probe.

The native command boundary and independent guardian must accept only one of
the actual owned replay modules, `Candidate` or `Total`. Its canonical regular
scratch `.olean` must exist. Reject flags, empty or multiple targets, paths,
other module names, symlinks, and an identically named scratch directory before
starting a native child. Keep ordinary replay and its imported-module checking;
do not switch to the weaker `--fresh` mode.

The prewritten artifact driver exercises the actual exported native boundary
with invalid requests and a deliberately nonexistent tool root. Every request
must fail with the replay-argument error and create no start witness. No real
runtime binary is needed or executed for this refusal check. Full native E2E
must still check the legitimate Candidate and Total paths. This narrow check
does not establish kernel, sandbox, memory, or resource qualification.
