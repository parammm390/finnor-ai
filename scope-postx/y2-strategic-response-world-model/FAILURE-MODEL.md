# Failure model and observable contracts, before critical code

## Learning and identification

* A policy label substitutes for its rule meaning, or equivalent labels change
  predictions. A saved label/hand-coded response replaces actual fitting.
* Independent actor marginals lose simultaneous participation, common-regime
  or cross-actor temporal dependence.
* Observational fit is called causal identification. A forbidden/uninformative
  intervention removes alternatives. Scaling-equivalent coefficients are
  mistaken for identified private preferences.
* A model set is weighted without evidence, truncated optimistically, or an
  incomplete hypothesis/trajectory search is described as exhaustive.
* Model-generated observations, future outcomes, unauthorized private data,
  hidden oracle state or forbidden S2 exposure enter the learner.
* Fitted state cannot be reconstructed from exact admitted evidence and the
  registered finite class. Updating silently edits Y1 or the objective.

## Behavior, numerical and economic meaning

* A threshold tie silently chooses participation; a convenient initialization
  selects an equilibrium; finite-horizon behavior is mislabeled Nash, unique,
  stable or empirically relevant.
* Actor response uses another actor's simultaneous/future action or information
  outside the registered local lagged graph.
* Shared regimes are independently resampled per actor. Fixed parameters change
  opportunistically between periods or candidate programmes.
* A solver budget failure is INFEASIBLE. Nonfinite arithmetic, byte overflow,
  model combination overflow or unsampled behavior yields a narrow interval.
* Model-relative likelihood/support becomes a calibrated field probability.
  Predicted participation becomes consent, reserved funding or settlement.
* Float conversion silently changes exact canonical money/unit/currency/time/
  owner/rounding/status semantics.

## Owner and durable runtime

* Authentication or Work/root/principal ownership is bypassed. Evidence/version,
  rights, policy meanings, regime, checker, runtime or learned-state changes
  escape submission/claim/check/publication/use fences.
* A queued job without a physical claim publishes. Expired leases, duplicate
  delivery, cancellation or killed workers/checkers resurrect work or capacity.
* Retry/replacement/fallback creates a fresh budget/deadline or erases costs.
* Admission uses the S5 finite allocation or Y1 domain. An unadmitted model is
  consumed. A development receipt becomes protected/production authority.
* S4 stores model metadata but evaluates identical historical worlds under all
  rules; a mock planner substitutes for actual synthesizeContingentControl.
* S5 is bypassed or a parallel ledger is created. S6 UNKNOWN/obligations vanish
  on cancellation, invalidation or model withdrawal; an effect is replayed.
* Fallback is a string instead of executed compatible original-budget behavior.
* An immutable checked artifact is overwritten. A transport withdrawal erases
  earlier observations, commitments, model attempts or unaffected claims.

## Product, installation and evidence

* Delayed old-principal results reappear after token/Work/root/logout changes.
  Offline/reconnect or revocation leaves private results active.
* A prediction is displayed as actual business completion. Controls are detached
  from canonical routes or inaccessible.
* Builder dependencies or hidden source/assets are absent from installed code.
  Generated contracts, migration prefix or old readers/jobs are incompatible.
* Reconstruction borrows build trees, dependencies, Git objects or alternates.
  Changed runtime code is certified by an earlier receipt.
* Failed/unstarted/omitted cases are removed; threshold/deadline/seed/population is
  changed after exposure. A fixture becomes protected/field/comparator evidence.
* Costs from failed fitting, checking, storage, fallback, acquisition and
  maintenance disappear or missing meters become zero.

## Independent checking contract

The engineering checker is a separate bounded Python standard-library process,
with no producer imports, database credentials, network/provider credentials or
oracle inputs. It independently enumerates the registered local coefficient/tie
class, checks every admitted fitting row, reconstructs complete equivalence
classes over the finite response domain, and recomputes joint withheld-policy
trajectories, support bounds, calibration and decision outcomes. Every receipt
binds exact input/candidate/profile/checker/interpreter identities.

Separate engineering algorithms/processes are not separately governed protected
evaluator custody. Protected evaluation remains NOT_RUN.

## Observable acceptance

Before informative admissible evidence, retain complementary and crowd-out
families and their adverse decision consequences. Uninformative evidence leaves
the ambiguity. Forbidden acquisition is denied. After informative permitted
evidence, construct fresh joint predictions for changed outside options and
compare them with independently generated synthetic observations. Revoke the
transport basis later; fence affected use while preserving actual earlier
commitments. The API/queue/SQL/S3/S4/S5/S6/Work boundaries must really be reached.
