# Preimplementation finite contract

This profile is a new, explicitly bounded S3 response-model family, not a
relaxation or replacement of the existing 64-training/20-holdout S3 gate.
The first profile has 2–3 binary actors, at most 4 periods, 8 registered public
rules and 486 candidate structural models. All supported preferences and ties
are enumerated. No likelihood, prior, posterior or uniform model weight exists.

For each actor, the learner enumerates its bias in `{0,1,2}`. The full model
shares an incentive weight in `{1,2}`, a peer weight in `{-2,0,2}`, and one of
participate/decline/inertia tie selections. A response sees only its own outside
option and previous choice, the current public rule, the public common signal
and, when disclosed, the previous peer count. No response receives another
actor's private type, current choice, solver world identity or future signal.
All actors choose simultaneously from the previous joint state.

Training eliminates inconsistent models only when the canonical assumptions
declare complete information, sequential exogeneity and stable types, and the
row is incumbent observational or an **executed permitted randomized**
intervention. A requested experiment is not data. Other intervention rows are
retained for descriptive diagnostics, not causal elimination. Holdout is never
used for selection. Report exact joint complete-trajectory set coverage
separately from identification, empirical calibration and omitted-model error.

The S1 canonical evidence-source version must contain the entire strict typed
`strategicResponseProblem` preimage. Its actor information, observations,
registered rules, payoff dimensions and transport assumptions are validated
as meanings, not accepted from an opaque hash. Source/root/rights and current
latest version must resolve through the existing owner. No Y2 evidence store.

Prediction enumerates each retained model with each complete joint private
path and each complete shared signal path. These are explicitly authorized
possible combinations, without probabilities. Worlds are never resampled or
independently marginalized over actors or time. Requested rule schedules must
resolve to the exact registered public mechanism (incentive, interaction,
disclosure, settlement) and declared transport domain.

The S4 bridge uses the existing evaluator and its unchanged owner mandate,
hard worst-path floor, resource checks, obligations and STOP incumbent.
Only safe integer canonical S5 `ResourceQuantity` money can cross this first
bridge; there is no rounding. Each actual S4 action context selects the bound
public rule, checked against its numerical schedule. Private state lives in
the adapter closure, never in lawful observations or policy preconditions.
An independent Python process re-enumerates fitting, joint prediction and
the bounded S4 selected programme. Its checker imports no producer logic.
It must reject missing alternatives and a falsely favorable decision.

Jobs use the canonical durable queue, physical claim/fence and native compute
leases. Each Work has one original finite episode across descendants, retries,
predictions and decisions. Conservative occupied work is not billed cost.
Checkpoints, immutable preimages and append-only cost events survive failure.
Cancellation invalidates future model use but never deletes S5/S6 commitments.
P7 invalidates only dependent continuation, not prior observations/effects.

S8's `STRATEGIC_RESPONSE_MODEL_SET` receipt is a separate disposable-development
domain. It is not Y1 admission, X4 admission, scientific validation, execution
authority or protected release. Fallback must be an admitted current model
with identical typed problem, source, Work cut, rights, method and original
episode. Otherwise no executable fallback is claimed.

## Additional failure predicates, fixed before implementation

* actor-local input includes current peer choices, private peer types or future
  public information;
* filtering holdout, labels, requested experiments or confounded interventions
  produces a falsely identified single family;
* zero supported models is called physical economic infeasibility;
* an omitted alternative improves worst-case programme value;
* model/path/world overflow is truncated instead of reported unsupported;
* action identity, original S4 utility or risk changes during lowering;
* a checker timeout or missing interpreter becomes checked feasibility;
* replay resets Work deadline, charged attempts or cumulative uses;
* stale worker or currentness check publishes after cancellation or mutation;
* installed checker/profile/method identity differs from the admitted source;
* tenant/principal/root change allows stale browser payloads or results;
* conditional finite fixture success is reported as field identification,
  protected qualification, equipped-X gain or realized financial benefit.
