# Preimplementation failure model and challenge value bar

Each row defines one observable invariant, a credible regression, and the
strongest owner-boundary proof. Upstream suites do not exercise S4 policies.
No challenge requires a test-only production seam; existing auth header bypass
and disposable ordinary-role PostgreSQL are labeled fixture boundaries.

| Invariant | Credible failure | Proof |
|---|---|---|
| One supplied economic problem | fabricated weights, priors, discounts, free costs, mixed units | mandate parser rejects missing/mismatched semantics; independent complete-utility oracle |
| Nonanticipative choices | per-world actions, leaked future signal/actor or later revision | same visible histories yield identical choices; changed hidden truth cannot change pre-signal decision |
| Fixed correlated ambiguity | sum of stage minima, equal mechanism weights, interval midpoint | independent full-path worst-case oracle, crossed multi-period scenarios |
| Joint information/action value | entropy score, omitted information costs/delay/exposure | known finite optimum with informative, costly, noisy and useless signals |
| Full consequences | stop deletes debt, horizon truncation, blind reversal/reissue | original-horizon independent rollout plus unknown-obligation withholding |
| Coupled resource demand | per-action capacity mistaken for aggregate feasibility | concurrent occupancy/cumulative budget and exclusive branch demand check |
| Honest solver certificates | unchecked fallback, false optimality, omitted rejected choices | independent policy readback/evaluation; budget truncation with wide gap retained |
| Qualifications preserved | posterior on bootstrap, unsupported trajectory/transport, temporal→IID | actual S3 fit/kernel and S2 protocol checks; unsupported returns explicit state |
| Exact current bindings | stale sources/rights/time/allocation, tenant leaks | actual owner handlers under ordinary role and foreign/revoked/tampered refs |
| Linked recovery | overwritten policy, duplicate choice, lost known/unknown commitments | immutable store restart/readback and history-bound decision identity |
| No fabricated downstream owner | unsigned clearance, self-issued receipt, dispatched effect | forged input rejected, BLOCKED states and DB independent zero-effects readback |
| Bounded computation | explosive tree/bytes/concurrency, unmetered cost called zero | registered caps, elapsed/CPU/RSS records, exhausted search and concurrent calls |

Model/simulator validity, numerical value, optimality, protected admission,
physical settlement and realized attribution are separate claims. Local ordinary
files can detect a content mismatch but cannot establish protected order/rollback
resistance. Failure artifacts are retained. No post-code unit tests will be added.
