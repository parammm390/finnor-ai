# Native observation boundary (primary takeover, before repair)

Existing failure-model families Native completion, Time, Unknown effect, Currentness and Protected boundary govern this check. The retained source had a Request observer and pre-code canonical-field corpus, but no actual creation-time deadline check and only Request-specific continuation.

The independent canonical row must match every frozen operation field, tenant, subject, result identity and original obligation deadline. Completion time is the owner's actual `created_at`, never the caller's backdatable requested timestamp. A late created row with an earlier requested timestamp must refuse observation. Request creation proves creation only; it proves neither fulfillment nor approval.

The same native continuation must support the frozen profile's three ordinary operations with distinct canonical readers and postconditions: Request, Workstream and Finding. It must preserve the original action/result identity, parent S5 reservation, grant, deadline, Work/input and generation/claim fence. A matching action found on recovery is reconciled before another submission. Any governed S6 origin refuses ordinary protocol 2. Cancelled or stale heads cannot publish observed completion, and possible effects keep their exposure.

Coverage gap: the pre-existing observer tested frozen Request fields but accepted a backdated, actually late creation; the Workstream and Finding observer paths were absent. These are the existing A/C/D/E owner cases, not a new broad campaign. Raw pre-repair outcome is retained privately. Database migration, physical dispatch and independently read canonical state remain required in the frozen live stage.
