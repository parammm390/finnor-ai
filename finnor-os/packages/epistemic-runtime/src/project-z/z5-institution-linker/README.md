# Z5 fixed-component institution composition

`kernel.ts` expands the **original coupled finite product**, including shared
cells, original initial tuples, internal steps, rendezvous, failures and
environment inputs. It then checks a conditional safety/nonblocking context.
It does not compose independent “safe” badges or erase coupling.

The supported correspondence is `BOUNDED_TYPED_KERNEL_V1`, with
`EXACT_LISTED_KERNEL_ONLY` scope. Every component revision is fixed before
linking. Replacement candidates are separately admitted inputs. No component,
grant, clean initial state or repaired transition system is synthesized.

`checker.py` is a separate standard-library process implementation. It
reconstructs the original product, translation, discharge, context closure,
public-offer uniformity, nonblocking ranks, replacement relation and actual
live-state bridge. It does not import or execute the producer. Both programs
and all public cases are builder controlled. This is not protected custody
or independently governed qualification.

## Meaning and limits

- The context is a **sound subset**, not a weakest or maximally permissive
  environment. Empty/circular discharge cannot establish a certificate.
- Every original component step, including may and failure steps, must remain.
  Required environment offers and lawful public observations stay explicit.
- Nonblocking means a finite path to completion or explicitly legal
  quiescence exists. It does not promise completion on every infinite
  schedule. An environment may delay indefinitely.
- Replacement uses
  `SHARED_STATE_EXACT_STRONG_MAY_SIMULATION_MUST_AVAILABILITY_LEGAL_QUIESCENCE_NONBLOCKING_V1`.
  The certificate exposes the relation and a bridge from the actual reachable
  live state. Original shared cells and unresolved liabilities are carried.
  An unbridged replacement yields `RETAIN_OLD`, not a clean reset.
- Limits: 2–16 components, at most 32 states per component, 16 ports,
  eight shared cells and 4096 context states, plus explicit original-product,
  transition, translation, relation, operation and wall budgets. Their full
  Cartesian product may be much larger. Exhaustion is `INCOMPLETE`, never
  infeasibility or a pruned completeness proof.
- A digest pins bytes. It does not prove arbitrary TypeScript, SQL, provider,
  private-information, financial or institutional behavior.

The kernel deliberately provides no DB, Auth, queue, admission or financial
authority. Concrete native adapters live in the corresponding private-equity
owned leaf. Shared source changes are frozen, unapplied coordinator requests
under `scope-z/phase-evidence/z5/integration/`.
