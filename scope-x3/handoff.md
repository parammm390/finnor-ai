## Outcome and exact scope

`EnterpriseApplicationPackage`. A business declaration compiles to checked,
data-only backend instructions, generated forms and immutable assets. The
existing Work interface, authenticated API, durable worker and ordinary

## Reconstruct and rerun

Use Node 22 and the repository's existing lockfiles. Run `npm ci` at the repository
root and in `finnor-os`. No new npm dependencies are required. Use a non-root
Linux environment with the libraries required by `embedded-postgres`.

For canonical scientific-owner effects, create a private Python 3.12 environment
and install the existing pinned
`finnor-os/packages/epistemic-runtime/src/intervention-requirements.txt` and
`requirements-s5.txt`. Set `FINNOR_S3_PYTHON` and `FINNOR_S5_PYTHON` to its absolute
interpreter path. `agent-browser` with working Chromium is required for the UI.
Do not supply production credentials.

From `finnor-os`, with a fresh absolute evidence directory:

```sh
export NODE_OPTIONS=--max-old-space-size=4096
export FINNOR_X3_BUILT_API=1
export OUT=/absolute/path/to/fresh-x3-evidence
npm run build --workspace @finnor/api
FINNOR_X3_EVIDENCE_DIR="$OUT/migration" node --import=tsx scripts/x3/migration-proof.mts
FINNOR_X3_EVIDENCE_DIR="$OUT/installed" node --import=tsx scripts/x3/run-installed.mts
FINNOR_X3_EVIDENCE_DIR="$OUT/effects" node --import=tsx scripts/x3/run-effects.mts
FINNOR_X3_EVIDENCE_DIR="$OUT/interface" node --import=tsx scripts/x3/interface-consumer-check.mts
FINNOR_X3_EVIDENCE_DIR="$OUT/browser" node --import=tsx scripts/x3/run-browser.mts
```

The last command prints `X3_BROWSER_FIXTURE_READY`. In another terminal with the
same environment, run
`FINNOR_X3_EVIDENCE_DIR="$OUT/browser" node --import=tsx scripts/x3/browser-checks.mts`.
The normal driver closes its own browser and fixture. Retain a failed campaign;
use a fresh directory and fixture, not a resumed partial pass. COMPLETE,
SMOKE_ONLY and SMOKE_PLUS_FAULTS reports are distinct.

From the repository root, run
`node scope-x3/verify-handoff.mjs /absolute/path/to/audit.json /absolute/path/to/evidence`.
The audit writes only its requested report and does not modify accepted evidence.
Source changes require restamping, rebuilding and restarting before a scored
campaign; do not edit the pinned paths during a run.

Affected validation includes backend/frontend TypeScript, strict campaign
TypeScript, scoped frontend/generator/audit lint, both emitted Next builds,
generated workspace/client/manifest/forms/authz/action contracts, domain
boundaries and production mutation inventory. No post-code unit tests were
written. Raw artifacts and receipts identify actual reruns and failures.
